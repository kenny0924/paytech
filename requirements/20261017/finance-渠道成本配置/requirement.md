# Finance 渠道成本配置

状态：阶段 1 已确认（2026-10-17）：用户回复“继续”，范围与 D1—D5 按建议执行。

## 1. 背景与目标

FIN-04“计算预计渠道成本”与 [Finance 数据库设计](../../../agent-docs/database/FINANCE_DATABASE.md) `channel_cost_plan / _ver / _scope / _component`：按 Channel 维护 Maker-Checker 成本方案版本，版本内以 MID、经营主体、国家、币种、支付方式、动作类型精确定义适用范围，每个范围下以费率、固定费与上下限定义成本组成；交易经济计算时按精确唯一命中估算预计渠道成本，无规则时拒绝估算，不默认零成本。

这是[交易自动记账依赖清单](../../20261016/finance-交易自动记账/dependencies.md) X5 中 Finance 自有、无跨系统依赖的部分。X5 的另一半“渠道清算账户维护”因创建时必须核对 Payment 权威 MID 元组（数据库设计全局不变量 49），而 Payment 当前没有 MID 查询接口，本期不做，在依赖清单中新增 X6。

使用者：Finance 内部与运营配置人员（内部开发接口，不接 Gateway/授权，Maker/Checker 由请求传入）。

## 2. 本期范围

| # | 内容 |
|---|---|
| P1 | 成本方案与版本 Maker-Checker：每个 Channel 一个方案；版本以完整适用范围与成本组成一次提交；冻结内容摘要；提交、批准（到期即切换当前版本、原版本停用）、驳回；查询 |
| P2 | 成本估算领域服务：按 MID、经营主体、国家、币种、支付方式、动作类型、计费基数与发生时间精确唯一命中适用范围，逐组成计算（费率 × 基数 + 固定费，受上下限约束，按币种精度舍入），返回逐项结果与规则证据；未命中或多命中拒绝 |
| P3 | 依赖清单新增 X6：Payment 提供 MID 查询接口，供渠道清算账户维护使用 |

## 3. 明确不做

渠道清算账户维护（依赖 X6）、实际成本确认与分摊（渠道清算对账）、交易经济创建、到期自动切换、页面、Gateway/授权。

## 4. 已确认决定

| # | 决定 |
|---|---|

## 5. 验收标准（草案）

| 编号 | 标准 |
|---|---|
| AC-1 | 创建方案：同一 Channel 或同一方案代码重复被拒；新方案为 DRAFT 且无当前版本 |
| AC-2 | 创建版本：适用范围与组成完整校验（维度非空、范围序号与语义维度不重复、组成代码不重复、费率 [0,1]、固定费与币种成对、上下限非负且下限不大于上限），内容摘要冻结；已有待处理版本时拒绝 |
| AC-3 | 提交 / 批准 / 驳回：仅编制人提交；Checker ≠ Maker 且确认同一摘要；到期批准切换当前版本、方案 ACTIVE、原版本 INACTIVE；未到期 APPROVED；驳回 REJECTED |
| AC-4 | 估算：唯一命中时逐组成返回原始金额、舍入金额与证据（版本、范围、组成、摘要）；无方案、无生效版本、无命中范围均拒绝 |
| AC-5 | `clean verify` 通过 |
