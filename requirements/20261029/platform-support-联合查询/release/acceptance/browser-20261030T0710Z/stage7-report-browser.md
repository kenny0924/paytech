1. **[联合查询 · 体验，非阻断] 1440 宽、7 个分组时，最右泳道被截在画布外。**
   - 现象：运营台有 200px 侧栏，画布约 1190 宽；7 个泳道按最窄 160px 排开约需 1320px，“对账”泳道只露出一半，要拖动画布才能看全。截图 `zh-CN-1440-B3-02a-order.png`。
   - 建议：泳道最窄宽度降到约 140px，或画布右侧加渐隐和可横向滚动的提示。
2. **[工作流 · 非本需求] 工作流实例列表在 390 宽横向滚动（zh-CN / en）。** 表格列宽超出视口，“进度”列文字被挤成竖排。截图 `zh-CN-390-B9-workflow.png`。本次未改动该页面，交给工作流会话。
3. **[税务 · 与预期表述的差异，供税务会话确认]** 页面显示的是**税额**（暂估 5.00、最终 15.00）和最终应付 115.00；r1 暂估那一行没有显示对应总额 105.00，也没有显示 5% 税率。若预期要求页面出现“105.00”或“5%”，需要税务会话确认；按目前的设计，这可能就是预期的展示方式。
4. **[联合查询 · 小] 入口节点 0 行时显示“起点 · 0”。** 渠道交易号入口的“渠道回调”节点如此显示，含义可读；如希望与普通节点一致，可改为“起点 · 无数据”。
