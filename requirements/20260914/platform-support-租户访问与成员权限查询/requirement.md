# 租户访问管理与客户/合作伙伴成员权限查询

阶段 1 范围、验收及逐阶段安排和阶段 2 分析均已由用户“可以”确认，成员显示/筛选已收敛为脱敏邮箱与账号 ID。阶段 3 详细方案见 [design.md](./design.md)，接口/数据/Pencil 方案已确认，进入阶段 4 研发及开发回归。确认记录见 [delivery.md](./delivery.md)，实际阶段与实施状态见 [当前台账](../../../agent-docs/CURRENT_IMPLEMENTATION.md#platform-tenant-access-20260914)。关联既有 PLT-15、PLT-I02、E2E-16，不另建一套 Tenant IAM。

**一句话总结：本期拟交付租户访问管理、成员权限查询 2 项业务能力，覆盖 Client 与 Local Partner；Operations 提供入口，Platform 拥有事实，精确 API、表字段、注册 DML 和页面数量在后续方案阶段确定。**

## 1. 目标与使用场景

使用者为有对应权限的 Operations 人员。运营能够找到一个客户或合作伙伴的访问租户，判断其访问受限原因，执行租户安全暂停/恢复，并查询成员有哪些角色、权限来自哪里以及为什么当前未生效。

- 客户反映无法操作：选择该 Client，查看来源业务状态、平台安全状态、成员状态及角色授权有效期，定位已知限制。
- 发现某租户异常使用：有管理权限的运营填写原因后暂停该租户访问；不会停用同一账号所属的其他租户。
- 排查结束后解除安全暂停：恢复平台安全状态；若 CCT 来源业务状态仍非 ACTIVE，页面继续说明租户访问条件未满足。
- 合作伙伴成员反馈缺少权限：运营只读查看成员及授权来源，日常成员和角色调整仍留给相应 Console 的后续功能。

## 2. 本期功能

| 编号 | 功能 | 拟交付范围 |
|---|---|---|
| F-01 | 租户列表 | 分页查询 CLIENT、PARTNER，按类型、租户 ID、所属客户/合作伙伴 ID、名称、业务状态、安全状态筛选；包含已暂停或终止的记录用于排查 |
| F-02 | 租户只读详情 | 显示租户标识、类型、所属主体标识、投影名称、来源业务状态、平台安全状态和租户层面的访问限制；不将两种状态合并成可手工编辑的一个状态 |
| F-03 | 安全暂停与恢复 | 独立管理权限、明确目标、填写非敏感原因并确认；只切换该租户的 Platform 安全状态，复用现有审计，并发或重复提交不覆盖他人的更新 |
| F-04 | 租户成员查询 | 在选定租户下分页查看成员标识、账号标识、脱敏邮箱（为空时显示账号 ID）、成员类型、成员状态和账号状态；可按账号 ID、脱敏邮箱显示值、成员类型及状态筛选，已失效成员仍可查询 |
| F-05 | 成员角色查询 | 查看所选成员的角色编码/名称、角色作用范围、角色状态、授予状态及有效期；不提供授予、撤销或角色编辑 |
| F-06 | 成员权限查询 | 查看权限编码、资源类型、操作及来源角色；同一权限合并展示并可展开所有授权来源，标注当前授权是否生效以及已知未生效原因 |
| F-07 | 查看与操作隔离 | 分开控制租户查看、租户安全管理、成员权限查看；无对应权限不能通过直接 API 请求获取或修改，既有审计按其自身权限查看 |

## 3. 状态及权限语义

### 3.1 租户状态

| 项目 | 数据 Owner | 含义与本期权限 |
|---|---|---|
| 来源业务状态 `owner_status` | CCT；Platform 保存投影 | PENDING、ACTIVE、SUSPENDED、TERMINATED。本期只读，不代替客户/合作伙伴业务审批、停用或终止 |
| 平台安全状态 `security_status` | Platform | ACTIVE、SUSPENDED。本期提供安全暂停和恢复 |
| 租户访问条件 | Platform 根据上述状态派生 | 普通租户访问要求两者均为 ACTIVE；不是新增可编辑字段，也不代表所有成员或凭证都可以访问 |

1. 本期查询和安全操作仅覆盖 CLIENT、PARTNER，不开放 INTERNAL 租户，避免通过此入口修改 Operations 自身访问租户。
2. 暂停作用于所选租户的访问资格，包括该租户的人工访问，以及 CLIENT 租户下的 API 凭证认证；不修改全局账号、其他租户、成员、角色、Scope 或凭证本身的状态。
3. 恢复仅解除安全限制。即使来源业务状态尚未恢复，也可清除安全暂停，但必须明确显示剩余限制；已撤销/过期的成员、授权和凭证不会因此恢复。
4. 来源业务状态后续变为 ACTIVE 不能覆盖安全暂停。租户安全操作不修改来源版本或来源内容；并发来源更新与人工操作的精确处理在阶段 3 定义。
5. 暂停提交后的新租户授权/认证检查应拒绝。不会取消已经进入业务处理的订单、支付或异步任务，也不以此功能替代注销所有会话。未建设的 Client/Partner 登录与会话链不因本期提供管理入口而被视为已接通。
6. PENDING 租户的入驻 Account Context 与普通 Tenant Context 不同。本期显示“普通租户访问条件未满足”，不据此推断其无法登录全局账号或查看入驻申请。

### 3.2 成员权限口径

- 成员权限查询固定在一个明确租户内；同一 CUSTOMER 账号在其他租户中的角色不能混入当前结果。
- 角色授权记录与当前有效授权分别展示。计算口径需考虑账号 Realm/状态、成员状态、租户状态、角色作用范围/状态、成员角色授权状态及有效期、角色权限关联和权限状态。
- 同一权限有多条角色来源时，只要至少一条满足全部条件，即可列为当前有效授权；同时保留其他来源的未生效原因，不让一条过期授权遮蔽另一条有效授权。
- 未生效原因使用可读说明，例如“租户已安全暂停”“成员已撤销”“角色已停用”“授权尚未生效”“授权已过期”。未知或损坏的关联不能推断为有效。
- 这里展示的是平台当前授权事实与已知限制，不执行一次业务请求，也不承诺某笔订单等具体资源可操作；实际入口、会话、业务资源归属仍由已有认证及业务 Owner 检查。未获授予的全部目录权限无需铺满为拒绝结果。
- 不新建权限缓存表、诊断结果表或另一套权限规则。后续分析确定当前逻辑的可复用部分和需补齐的 CUSTOMER 查询口径。

## 4. 功能验收

| 编号 | 可验收结果 |
|---|---|
| AC-01 | CLIENT/PARTNER 分页、筛选及详情正确；已暂停/终止租户可排查，INTERNAL 不进入本期列表或直接详情/命令接口 |
| AC-02 | 来源业务状态与平台安全状态分别展示；来源非 ACTIVE 时，解除安全暂停仍显示剩余限制，不宣称完全可访问 |
| AC-03 | 有管理权限者可填写原因暂停/恢复指定租户；只读人员、失效身份或缺少原因的请求不能操作 |
| AC-04 | 暂停/恢复只变更目标租户的安全状态及必要版本/时间元数据；来源状态/版本、其他租户、账号、成员、角色与凭证状态不被改写 |
| AC-05 | 安全暂停提交后，真实 PLT-I03 对该 CLIENT 的新认证拒绝；其他条件均有效时恢复后可认证，已撤销/过期凭证及来源非 ACTIVE 租户仍被拒绝 |
| AC-06 | 重复操作结果可识别，旧版本或并发冲突不会静默覆盖更新；通过既有审计查询本期操作和原因，不伪造缺失历史 |
| AC-07 | 成员列表与详情固定在目标租户；使用其他租户的成员 ID 不能串读，同一账号多租户的成员关系分别展示 |
| AC-08 | 角色及权限展示授权状态、有效期和来源；未来生效、过期、撤销、停用、租户/账号/成员受限及越界角色均有正确口径；多来源权限正确合并 |
| AC-09 | Operations 无邀请成员、编辑成员、增减角色/权限或客户主档管理入口；查询响应和普通日志不包含明文邮箱/电话、Vault Token、密码校验值或认证秘密 |
| AC-10 | 原 Operations 登录、菜单、角色、Scope、凭证和风控页面保持兼容；通过真实管理链与本地合成数据验证本期功能，未实施的 CUSTOMER 登录链明确列为未验证 |

## 6. 本期不做及依赖边界

不做租户手工创建/删除、CCT 客户或合作伙伴主档编辑、入驻审批/投影生产链、成员邀请/新增/编辑/撤销、角色和权限授予、全局账号停用、Client/Partner Console 研发、客户登录/注册/切换租户功能、会话中心、凭证批量撤销、Webhook、通知、文件或业务执行。

租户与成员使用 Platform 已有模型；正式业务租户来源仍为 CCT，不通过 Operations 创建虚假来源记录。开发使用受控合成数据，test 是否准备示例及其内容在发布准备时列明。本阶段不执行数据库操作。

当前人工授权实现以 Operations 为范围，不能直接用它声称 CUSTOMER 成员权限已经支持。阶段 2 必须核对实际消费链；本期至少完成真实管理查询/写入和既有 PLT-I03 的生效验证。若要扩展新的 CUSTOMER 运行认证链，需另列影响并确认，不能作为隐藏依赖带入本期。

## 7. 确认点与后续阶段

已确认事实：用户选择两项能力一起做；成员日常管理归对应 Console；Platform 拥有 Tenant IAM；来源业务状态与安全状态分离；原 API 版本或默认 v1，代码类型名不含版本号。

本阶段已确认：**CLIENT/PARTNER 共用管理入口；Operations 只管理租户安全暂停/恢复；成员和授权只读；安全暂停影响租户人工访问资格及 Client API 认证，恢复不覆盖其他限制。** 具体源码缺口、环境前置和成员显示细化见阶段 2；无需用户先提供账号、表字段或接口路径。

适用阶段为需求评审 → 差异与影响分析 → 接口/数据/Pencil 方案 → 研发及开发回归 → 综合验证 → test 发布准备 → 获授权部署与验收 → 获授权提交归档。每阶段交付后停下确认；实际确认、实施和部署状态见[当前台账](../../../agent-docs/CURRENT_IMPLEMENTATION.md#platform-tenant-access-20260914)及[交付记录](./delivery.md)。
