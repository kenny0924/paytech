## 1. 入口、筛选与导航

独立根菜单“租户访问”，位于平台配置之后；其可见性只依赖 TENANT_ACCESS_READ，不附加 Gateway 配置权限。路径方案：

- `/tenant-access`：租户列表；筛选明确为类型、名称、租户 ID、所属客户/合作伙伴 ID、业务状态、安全状态，全部 AND 关系；每个字段对应 [A01](./api.md)。
- `/tenant-access/:tenantId`：租户详情；顶部名称、类型、Owner ID、双状态及租户限制，下面成员/操作记录页签。不能直接编辑业务状态。Member 查询对应 A04；操作记录复用现有审计及其查看权限，按 `ACCESS_TENANT + tenantId` 过滤。
- `/tenant-access/:tenantId/members/:memberId`：成员权限；顶部脱敏邮箱/账号 ID、成员 ID、状态和当前 Tenant；角色授权/权限与来源页签，A05/06/07/08 按需查询。

菜单组件 key 为 OPERATIONS_TENANT_ACCESS，页面能力声明允许本期路径和两个按钮，继续使用现有路由挂载方式实现嵌套路径。组件映射是前端能力，不是 Gateway 转发白名单。

点击“详情”“查看权限”以及主动切换页签使用正常历史导航；筛选、分页及 tab 放 URL 查询参数，筛选应用时 page=1。成员页 URL 始终包含 Tenant ID，直接刷新可重新读取。浏览器返回恢复真实上一页及查询上下文；不增加“返回来源页”“返回列表”等按钮，不把正常导航全改 replace。

## 2. 状态和操作

列表每租户一行，操作列用一个小型“操作”菜单，点击或悬停可展开。详情为普通色；安全状态 ACTIVE 显示红色“暂停访问”，SUSPENDED 显示“恢复访问”。鼠标、键盘和触屏都能打开；危险动作二次确认，Enter/Space 可操作，Escape 关闭并恢复焦点。

暂停弹窗显示租户名称/类型/ID、短影响说明、必填原因与确认/取消。恢复共用同布局，标题和主操作变“恢复访问”；不将正常恢复按钮标为危险红色。原因 trim 后 1..500 字符。提交中禁止重复点击；失败保留输入和原幂等键，网络结果不确定的重试复用原 Body/键。冲突时提示重读，不静默刷新版本后覆盖。

业务状态显示“待激活 / 正常 / 已停用 / 已终止”；安全状态显示“正常 / 已暂停”。租户访问条件只描述租户门槛。恢复后业务状态仍非 ACTIVE，出现就地黄色剩余限制提示；不能给出“已全部恢复可用”的成功文案。保存成功但重读失败，明确“操作已完成，详情刷新失败”，提供重试读取。

## 3. 成员及权限来源

成员显示脱敏邮箱；为空时直接用账号 ID，不创建姓名字段。账号 ID 与脱敏邮箱分别筛选，不按明文邮箱模糊搜索。成员类型固定为 OWNER/ADMIN/MEMBER，状态为 ACTIVE/SUSPENDED/REVOKED；选择器只展示业务可读标签。

成员和角色/权限只读，无保存、编辑成员、授予/撤销角色等按钮。角色授权表保留已撤销、尚未开始、已过期记录；授权有效期精确到需要排查的时间，hover/展开可看完整 UTC/本地显示。

权限页每 permissionId 一行，展示代码、资源/操作、当前授权状态和来源数量。点击来源展开小表，按需 A08 分页；允许看到一个来源有效、另一个过期。页面显示每次查询的 evaluatedAt；来源请求发生在另一时刻时保留各自计算时间，刷新整个页签可重算，不承诺跨请求一致快照。

表格固定列布局；长代码、名称、邮箱设置 min-width:0 与 ellipsis，hover/focus 提供完整的非敏感文本，不让权限码覆盖下一列。小屏容器内横向滚动，页面本身不出现不受控溢出；分页使用 10/20/50/100，不显示当前通用控件中不适用于本 API 的 200 选项。沿用现有分页结构，默认 10。

## 4. 权限、空与错误

| 场景 | 页面行为 |
|---|---|
| 无租户 READ | 菜单不可见；直接访问页面显示无权查看，不伪装成查无记录 |
| 有 READ，无 MEMBER_READ | 只显示租户头部，成员区域显示“无成员查看权限”，不发起成员查询；是否显示操作记录由审计权限决定 |
| 有 READ，无 MANAGE | 不显示暂停/恢复，但保留详情；后端仍独立校验写权限 |
| 没有成员/角色/权限 | 成功空态分别为“暂无成员”“暂无角色授权”“暂无已授予权限”，不暗示加载错误 |
| 有筛选但零结果 | “没有匹配结果”，可重置筛选；不同于租户没有成员 |
| 404 / 403 | 分别显示目标不存在/当前无权查看；不显示其他 Tenant 的内容 |
| 5xx/超时/数据不一致 | 独立错误块、Request ID、安全提示和重试；不把旧页的成功状态伪装成最新结果，也不显示空列表 |
| 单条来源查询失败 | 保留权限概览，在该展开区显示失败与重试，不将来源数改为 0 |

操作记录复用既有审计页的安全展示与分页，没有本期历史时保持空态；不构造假审计。Pencil 示意的“操作记录”对有审计权限的用户展示。

本阶段完成静态设计审阅和布局检查；真实响应式、键盘、后退、权限分支和接口联调在研发/综合验证阶段核对，不把 Pencil 当成可运行页面。
