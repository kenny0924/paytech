## 1. 定稿与模型

每账号一份未完成申请已确认，按数据稿落地账号唯一索引、原单恢复及上传目标核对。[迁移方案](./migration-plan.md)已区分空数据和非空历史数据；开发同步 PDManer、生成器、当前 Schema、Checkout 消费者和空闭包增量 SQL。不得只应用本目录局部目标表，也不能把非空环境历史处置当作允许删除数据。

注册使用[48 个 Owner 管理命令模板](./db/management-command-templates.json)，实际 ID 在发布时读取并绑定；37 条新路由先 DISABLED。研发补齐运营审核组件能力和 Client Cookie 链；没有 Owner 门禁、CLIENT 会话链和权限绑定时不启用。C02 外部路径须处于认证 Cookie Path，Route 超时不超过现有 10 秒硬上限。

## 2. 开发顺序

| 顺序 | 范围 | 可验收结果 |
|---|---|---|
| 0 | 目标模型、完整 Schema、Checkout 读取适配 | 模型/SQL 一致；空草稿不能参与 Checkout，稳定批准资料及共享引用可读取；只准备人工迁移文件 |
| 1 | Platform 认证、邮件适配、CLIENT Cookie/会话；Gateway 对应入口 | 注册、邮件链接验证、邮箱密码登录、刷新、退出、密码恢复闭环；原 Operations 行为保持兼容 |
| 2 | CCT 单份资料和申请命令 | 个人/组织空草稿创建、部分保存、稳定身份绑定、人员/关系/材料归属、批准锁定 |
| 3 | Platform 受控文件与扫描链 | 上传完成由服务器验证字节，跨目标访问拒绝，扫描不可用不能成为合格材料 |
| 4 | Risk 主/相关人任务及 Operations 审核 | 材料/检查/分类门禁；RETURNED/REJECTED/APPROVED；任务身份与幂等 |
| 5 | CCT/Risk 结果及 Platform 开通恢复 | 提交登记、分类传递、结果回调、Tenant/Member 开通均可从中断恢复 |
| 6 | Client/Operations BFF 和 Web | 按 Owner allowedActions 展示单页、抽屉、审核中、退回、通过、拒绝及开通中状态 |

BFF 负责经授权查询的组合和页面模型，不持有业务表或组织跨系统保存事务。敏感字段禁用普通 Body 日志。新实现测试先证明关键业务失败，再完成修复；只使用仓库规范的本地基础设施。

进入阶段 4 后第一批先交付表格中的 0 和 1：数据模型与读取兼容，以及“注册 → 邮箱链接验证 → 登录 → 刷新/退出 → 密码恢复”的可运行闭环，包含 Client BFF/Web 对应页面。真实邮件使用适配端口；本地验证允许受控 Simulator，必须标注证据边界。随后沿同一批准范围完成 2—6，不把首批完成当作整个入驻已实现。阶段 4 授权不自动执行数据库、配置外部服务、部署或提交。

## 3. 必须通过的业务验证

| 主题 | 最小验证证据 |
|---|---|
| 认证 | 不同账号存在性响应一致；Challenge 用途隔离、过期、旧链接失效、单次消费；GET 不消费；重置撤销会话；Refresh 并发/重放受控 |
| 草稿 | 只有姓名或半份证件也能保存和恢复；NULL 与遗漏字段区分；不存在占位值；非法类型/未知字段被拒 |
| 单份申请 | 个人/组织跨类型合计一个名额；两个并发新建只产生一份且无孤立业务对象；另一类型明确冲突；RETURNED 仍占用；终态释放允许新建；重放旧创建键不新建 |
| 身份 | 同身份重复绑定当前 Party 幂等；其他 Party 冲突不泄露；禁止改写永久键或未经授权复用批准资料 |
| 状态 | DRAFT/RETURNED 可编辑；SUBMITTED/UNDER_REVIEW/APPROVED/REJECTED 的每个写入口均拒绝；最终拒绝不能复活 |
| 人员 | 个人申请不能新增组织人员；同一人员多个关系；移除关系不删共享 Party；跨申请、跨账号和错主体文件均拒绝 |
| 分类 | Client 伪造行业/MCC 被拒；行业不自动推导 MCC；恰好一个主分类；分类未确认或尚未被 Risk 接收时不可批准 |
| 审核 | 主/子任务和必需证据/检查缺失时不能批准；退回关闭旧活动任务；新提交不得自动复用不适用的旧结论 |
| 上传归属 | 旧申请页面、唯一但错误的 Tenant、重复/延迟投影、Partner 候选均不能误选；上传完成沿用原归属；旧文件不自动关联后来申请 |
| 恢复 | 原命令同参重放返回原结果，异参冲突；每个跨系统中断点重试同一身份；旧任务晚到不能改变新申请状态 |
| Checkout 兼容 | 草稿不进入支付准备；已批准稳定 Profile ID/Hash 可读取；共享 Partner/OE/Agreement 历史引用仍有效 |

## 4. 页面验收

桌面双列、窄屏单列，组织人员抽屉可新增/编辑/移除关系。提交前有只读核对，只有收到保存成功才显示已保存；保存中退出提示不能丢失未发送内容。422 定位实际 JSON 字段，退回说明自动定位分区。无 Google/OTP、资料版本或批准后编辑入口。

必须测试真实键盘焦点、必填/禁用状态、网络中断、重复点击、文件扫描等待和 390px 宽度。Pencil PNG/无裁剪检查只证明静态设计，不替代这些浏览器交互验证。
