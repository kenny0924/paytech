## 1. 维护对象

Operations 的 API 配置下设置“接口配置 / 数据模型 / 公共脚本”三个入口。公共方案和独立脚本合并为公共脚本，不再维护方案类型、单能力/组合能力及另一套固定规则表单。

公共脚本在接入分组内以 scriptCode 定位，维护名称、执行阶段 REQUEST 或 RESPONSE、参数定义、源码及引用关系。一个分组允许多套签名/加密处理脚本；每个 API 显式选择，无隐式继承。复杂逻辑由代码注册的系统函数实现，脚本只做组装、转换、判断及函数调用。

API 保存有序脚本引用及参数绑定，不复制源码。参数结构由脚本定义；参数值由每个 API 设置。参数取值沿用上下文路径、Aviator 表达式、系统函数及 result 表达式；固定值使用表达式字面量。参数默认值仅在 API 未配置绑定时使用，运行时绑定出错不能静默回退。

公共模型继续维护输入和输出的结构；请求映射继续负责普通字段组装；响应场景及 outputs 映射继续负责返回给调用方的合同。公共脚本不替代这些配置。

## 2. 脚本执行环境

| 对象 | REQUEST | RESPONSE |
|---|---|---|
| context | 只读调用输入 | 只读调用输入 |
| params | 只读本步骤参数 | 只读本步骤参数 |
| http.requestHeaders | 读写 | 只读已发送请求 |
| http.requestBody | 读写，初始值来自请求映射 | 只读已发送请求 |
| http.responseHeaders | 不可用 | 读写响应工作副本 |
| http.responseBody | 不可用 | 读写响应工作副本 |
| http.method / path / query | 只读 | 只读 |
| http.responseStatus | 不可用 | 只读 |

支持修改 Body 内的嵌套字段、数组，以及整体替换 Body。后续脚本读取前序脚本修改后的对象；它们属于同一次调用的内存工作区，不修改调用方的 context，也不在调用间共享。脚本返回值不自动成为 outputs，异常中断并返回 ERROR / {}。

Headers 使用大小写不敏感、支持多值的受控容器。页面展示 get/set/add/remove 方法；方法签名、类型检查、多值读取及编码约束由运行时注册合同落实，不按普通大小写敏感 Map 执行。

签名和验签由系统函数处理：请求签名覆盖的字节必须与发送字节一致，受保护内容在签名后不能被无约束改写；响应验签读取当次内存中保存的原始响应，不读取脚本已经修改的工作副本。原始响应不增加持久化记录，也不开放给脚本覆盖。受控数据分类、凭据访问和敏感输出限制继续适用，不能借 HTTP 对象获得任意密钥或原始卡数据权限。

## 3. 执行顺序

```text
加载一致的 API、公共脚本及模型配置
  → 校验调用输入
  → 请求字段取值、必要的系统查询及 Body 组装
  → 按顺序绑定参数并执行 REQUEST 脚本
  → 校验最终报文及保护约束，发送最终字节
  → 接收原始响应，形成响应工作对象
  → 按顺序绑定参数并执行 RESPONSE 脚本
  → 校验处理后响应，匹配公共响应场景
  → 映射并校验 outputs
  → 返回 {executeStatus, outputs}
```

具体协议的解密、验签与解码先后顺序由受控系统函数的类型/保护合同决定。受保护 Body 尚不可解析时，不提前把它当作 JSON；解密函数可以将其替换为可映射结构。异常、验证失败、未匹配场景仍为 ERROR；不增加重试或运行期持久化。

响应映射页当前示例直接使用处理后的 `http.responseBody.state`、`http.responseBody.transactionId`、`http.responseBody.redirectUrl`；不再要求先生成独立的 facts 包装。系统函数产出的已校验投影仍可赋给工作 Body，之后照常做场景和输出约束检查。

S01/S02 保留原位置 `(0,29460)`、`(1540,29460)`，S03/S05 位于右侧 `(3570,29460)`、`(5110,29460)`。S04 保留原协议处理位置 `(0,24960)`。S00 索引标出这些位置；M01～M08 新增公共脚本导航，M05/M06 页签改为“脚本处理”，M06 使用新的响应工作对象路径。

- “新建脚本”打开空白编辑器；编辑回填当前脚本。阶段切换重新校验所有对象访问及引用 API，不能将无效脚本保存成可执行状态。
- 对象目录插入受支持路径；系统函数目录按阶段筛选，展示参数、返回与失败行为，“插入调用”放入源码模板。参数结构的添加/编辑采用名称、类型、必填、默认值控件，沿用数据模型的类型约束；画板展示已有参数状态。
- API 点击“引用脚本”进入 S05，仅选择当前接入分组和阶段可用的脚本；每个引用有自己的步骤标识和参数绑定。同一脚本可被不同 API 使用，不同 API 可传不同参数。
- “应用到参数”更新当前引用的局部草稿，“应用引用”更新 API 草稿，保存 API 后生效。局部修改未应用时，顶部保存不可跳过这些修改；取消引用编辑不改变原 API 草稿。
- 脚本源码单独保存，返回 API 时保留其未保存草稿并重新检查引用。共享脚本修改校验全部引用；破坏参数或阶段合同则拒绝保存并定位引用。被引用脚本不能直接删除；API 移除引用不删除公共脚本。
- 保存后的新调用使用当前配置；在途调用使用已加载内容，不引入版本发布。静态校验只读定义与注册目录，不执行脚本、查询、密码操作或 HTTP。
