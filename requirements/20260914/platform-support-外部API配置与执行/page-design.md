## 1. 使用者与范围

使用者是熟悉渠道文档的接入人员和 Platform 开发者。页面只维护配置，不执行外部请求。

| 维护对象 | 页面 |
|---|---|
| 标准 API 与字段 | 标准 API 列表、标准 API 编辑 |
| 接入方与出站地址 | 接入方列表、接入方工作区“基本信息”页签 |
| 原子 API 与字段 | 接入方工作区“原子 API”页签、原子 API 编辑 |
| 公共脚本 | 接入方工作区“公共脚本”页签、脚本编辑 |
| 渠道标准 API 实现 | 接入方工作区“标准 API 实现”页签、流程编辑 |

本期不做：试运行或调试调用、配置版本与发布、导入导出、操作历史。

## 4. 标准 API 编辑

```text
标准 API / PAY                                            [校验] [保存]
┌ 基本信息 ───────────────────────────────────────────────────────────────┐
│ 编码 PAY（创建后只读）   名称 [支付______]   说明 [________________]     │
└──────────────────────────────────────────────────────────────────────────┘
[请求字段] [响应字段]
┌──────────────────────────────────────────────────────────── [添加字段] ┐
│ 位置  字段路径                        显示名称   类型    必填  说明  操作 │
│ BODY  paymentContext                  支付上下文 OBJECT   是         ⋯  │
│ BODY  paymentContext.amount.value     支付金额   STRING   是         ⋯  │
│ BODY  paymentContext.items[].sku      商品编码   STRING   是         ⋯  │
└──────────────────────────────────────────────────────────────────────────┘
```

- 字段表按路径缩进显示层级；`[]` 标出数组元素，提示“父对象存在时才校验必填”。
- 字段编辑在弹窗中完成：位置、路径、显示名称、类型、必填、说明。响应页签的位置只提供 HEADER、BODY。
- 修改已被渠道实现引用的必填字段时，保存校验会列出受影响的流程（例如出口未覆盖新必填输出），不阻止编辑，但阻止保存。

## 5. 接入方工作区

```text
接入方 / NI                                                     [编辑]
[基本信息] [原子 API] [公共脚本] [标准 API 实现]
```

| 页签 | 内容 |
|---|---|
| 基本信息 | 编码、名称、说明；出站地址表（`endpointCode`、`baseUrl`），最多 16 行；提示“实际出站受部署网络白名单限制” |
| 原子 API | 列表：编码、名称、Method、地址代码 + 路径、脚本数、被哪些实现引用；新建/编辑进入原子 API 编辑 |
| 公共脚本 | 列表：编码、名称、阶段、参数数、引用 API；新建/编辑进入脚本编辑 |
| 标准 API 实现 | 列表：标准 API、节点数、出口数、总预算、更新时间；“新建实现”先选尚未实现的标准 API，再进入流程编辑 |

## 6. 原子 API 编辑

```text
接入方 NI / 原子 API / CREATE_ORDER                       [校验] [保存]
[接口] [请求字段] [响应字段] [调用参数与固定值] [脚本] [状态规则] [输出]
```

| 页签 | 维护内容 |
|---|---|
| 接口 | 编码（创建后只读）、名称、说明；Method、地址代码（下拉选本接入方 `endpoints`）、路径模板、连接/响应超时、请求编码、响应解码。路径模板中的 `{变量}` 与 PATH 字段双向提示 |
| 请求字段 / 响应字段 | 同标准 API 字段表，位置可选 HEADER/BODY/QUERY/PATH（响应只有 HEADER/BODY） |
| 调用参数与固定值 | 参数表（名称、类型、必填；类型可选 `PROTECTED_HANDLE`）；固定值表（选择请求字段，填常量表达式），已设固定值的字段在请求字段表上标“固定” |
| 脚本 | 有序列表，分 REQUEST、RESPONSE 两组；每行选脚本、绑定参数（只能用 `params.*` 或常量）；上移/下移调整顺序 |
| 状态规则 | 有序规则表：条件、结果（SUCCESS/FAIL）；末行固定显示“其他情况 → ERROR”，不可编辑 |
| 输出 | SUCCESS、FAIL 两个分支表：名称、类型、必填、取值；ERROR 固定为空对象 |

### 6.1 脚本编辑

```text
接入方 NI / 公共脚本 / NI_SIGN                              [校验] [保存]
编码 NI_SIGN（只读）  名称 [请求签名]  阶段 (●REQUEST ○RESPONSE)  说明 [____]
┌ 参数 ─────────────────────┐┌ 源码（Aviator）────────────────┐┌ 可用对象与函数 ─────┐
│ key  PROTECTED_HANDLE 必填 ││ functions.sign(params.key)     ││ http.requestHeaders │
│ [添加参数]                 ││                                ││ http.requestBody    │
└───────────────────────────┘└────────────────────────────────┘│ 注册函数目录…       │
引用此脚本的原子 API：CREATE_ORDER、QUERY_ORDER                  └─────────────────────┘
```

- 右侧对象树按阶段显示可读写对象：REQUEST 可写请求头和请求体；RESPONSE 可写响应工作副本，请求只读。
- 修改阶段或参数会校验全部引用的原子 API，破坏引用时不能保存。

## 7. 流程编辑（渠道标准 API 实现）

```text
接入方 NI / 标准 API 实现 / PAY                  总预算 [25000] ms  [校验] [保存]
┌ 初始化 ─────────────┐┌ 画布 ─────────────────────────────────────┐┌ 属性：createPayment 的出口 ┐
│ channelAccount      ││                                             ││ 1 执行状态 SUCCESS → paid  ↑↓│
│ CHANNEL_ACCOUNT_    ││ [开始] → [createPayment]                    ││ 2 执行状态 FAIL → declined ↑↓│
│ CONFIG · 必需       ││            ├ 1 → (SUCCESS 出口 paid)        ││ 3 执行状态 ERROR →         ↑↓│
│                     ││            ├ 2 → (FAIL 出口 declined)       ││   queryPayment               │
│ [添加初始化项]      ││            ├ 3 → [queryPayment]             ││ 其他情况 → unknown（固定）   │
│                     ││            │        ├ 1 → (SUCCESS 出口 paidAfterQuery) │                    │
│                     ││            │        └ 其他 → (ERROR 出口 unknown)       │                    │
│                     ││            └ 其他 → (ERROR 出口 unknown)    ││                              │
└─────────────────────┘└─────────────────────────────────────────────┘└──────────────────────────────┘
┌ 校验结果 ────────────────────────────────────────────────────────────────────────────────────────┐
│ ✕ 出口 paid：标准 API 必填输出 paymentStatus 未赋值                                    [定位]    │
└──────────────────────────────────────────────────────────────────────────────────────────────────┘
```

### 7.1 画布

- 节点类型：开始（固定一个）、原子 API 节点、返回出口（SUCCESS / FAIL / ERROR 三种颜色）。初始化项不上画布，放在左侧栏。
- 新建实现默认“开始 → 待配置出口（ERROR）”。添加节点时从本接入方原子 API 中选择，节点显示 API 编码、名称和必填字段覆盖情况（如 `请求 5/6`）。
- 只允许无环连线；拖出回到上游节点的连线时直接拒绝并提示“流程暂不支持环”。
- 每个原子 API 节点只能有一条“其他情况”出口，固定显示在最后。

### 7.2 属性面板

| 选中对象 | 面板内容 |
|---|---|
| 初始化项 | ID、注册函数（下拉）、参数取值、是否必需；失败行为固定说明：“必需项失败时不发送渠道请求” |
| 原子 API 节点 | ID、原子 API；“请求字段”表逐行赋值（固定值行只读）；“调用参数”表；未覆盖的必填项红色标出 |
| 连线 | 同源出口有序列表：条件、目标；上移/下移即重编优先级；“其他情况”固定最后 |
| 返回出口 | ID、执行状态；SUCCESS/FAIL 出口按标准 API 响应字段逐行赋值，ERROR 出口无输出 |

### 7.3 取值与条件编辑器

所有“取值”单元格使用同一个编辑器，三种方式：

| 方式 | 交互 |
|---|---|
| 路径 | 右侧变量树选择：`input`（标准 API 请求字段）、`resources`（初始化结果）、`steps`（**只列出必经节点**的输出）；不可用的节点灰显并提示“该节点不在所有路径上” |
| 表达式 | Aviator 单行编辑，变量树插入路径，常量直接写字面量 |
| 函数 | 选择纯函数、按参数绑定取值、填写结果表达式（默认 `result`） |

- `resources.*.credentials.*` 在变量树中显示锁图标“受控句柄”，只能选入类型为 `PROTECTED_HANDLE` 的调用参数，其他位置不可选。
- 条件编辑提供快捷项“执行状态为 SUCCESS / FAIL / ERROR”，生成对应表达式；也可切换为自由表达式。表达式只做语法与变量校验，不在页面执行。

## 8. 通用交互与状态

| 状态 | 处理 |
|---|---|
| 只读详情 | 无编辑权限或从列表“详情”进入；与编辑同布局，隐藏保存和增删操作 |
| 未保存离开 | 浏览器离开、切换路由时提示保存或放弃 |
| 校验 | “校验”按钮与保存均调用服务端静态校验；问题列表可定位到页签、字段行、节点或连线；有错误时保存失败、草稿保留 |
| 并发冲突 | 版本不一致时提示“该配置已被他人修改”，可重新加载后再编辑 |
| 删除保护 | 被引用的标准 API、原子 API、脚本、出站地址不能删除，弹窗列出引用方并可跳转 |
| 空状态 | 无接入方 / 无原子 API / 无实现时显示新建入口；新建实现时无可选标准 API 则提示“所有标准 API 已实现” |
| 加载失败 | 保留当前页面，显示重试，不清空草稿 |

所有修改保存后对**新调用**立即生效（无发布），保存按钮旁常驻提示该行为。
