# 任务卡 F · 阶段 5 本机全链路冒烟（commercial 真实进程 + HTTP）

> 依赖集成分支（D + B + C 合并且统一 BCR）编译与测试全绿。执行者 Opus 5.5 agent。只读源码、只起 commercial 进程、只调 HTTP；不改业务代码（发现缺陷记录并报告，由主会话裁决是否修）。

## 环境

- 进程：从集成 worktree 构建 `commercial-service` 可执行 JAR，用本机 JDK 25 直接 `java -jar` 启动，端口 18108 / 管理 19108。环境变量：`SPRING_DATASOURCE_URL` 指向 `mor_commercial_lineb`（已有 21 表；先执行目录初始化 DML `docs/database/sql/commercial-initial-data.sql`，由主会话执行）、`COMMERCIAL_RABBITMQ_*`（local-environment /mor-local，凭据取 `.env.local` 的 `MOR_RABBITMQ_*`）、`COMMERCIAL_REDIS_*`（16379，密码 `MOR_REDIS_PASSWORD`）、`COMMERCIAL_SNOWFLAKE_REGION_ID=0` / `WORKER_ID=30`（worker 仅允许 0–31，原卡写 33 有误）、`COMMERCIAL_XXL_JOB_ENABLED=false`、Nacos 可用 `--spring.cloud.nacos.discovery.enabled=false`（若应用允许；否则按 local-e2e 的 mor-local 命名空间）。client-master 不起：解析接口的 client-master 候选调用预期 503 OWNER_UNAVAILABLE，作为失败关闭证据记录。
- 调用头：`X-Caller-Service: operations-console-bff`（写入）与 `X-Gateway-Actor-Subject: <运营账号 ID>`（maker / checker 用两个不同 ID）。

## 冒烟流程（全部记录请求、响应状态与关键字段到 verification/stage5-smoke.md）

1. 画像：创建 `profile_kind=PAYMENT_METHOD`、`payment_method_code=CARD`、条件 CARD_BRAND=VISA + FUNDING_TYPE=CREDIT + ISSUER_REGION=DOMESTIC 的画像；再创建无条件的 CARD 兜底画像；两者激活；退役一个未被引用的第三画像。
2. 合同：创建 CLIENT 合同（MOR、SETTLE_THROUGH_PLATFORM、PLATFORM，entity_no 五位如 AE001，参与方 CLIENT + OPERATING_ENTITY，SIGNING_DOCUMENT 文件引用）→ submit-for-signature → 两个 Party 的 acceptance（CLICK_ACCEPTANCE）→ activate；校验 `AgreementStatusChanged` 到达 RabbitMQ（临时队列绑定 commercial.events）。
3. 订阅与开通：PUT products = [ACQUIRING]；POST capabilities CARD_VISA（AED、USD；REQUIRE_3DS=1；保证金 5% / 180 天）与 APPLE_PAY（AED）。
4. 条款：POST plan（CLIENT_PRICING）→ POST version → PUT prices（AED / USD × 两画像，组件 CAPTURE PERCENTAGE 2.5% + FIXED 1.00，AUTH FIXED 0.10，REFUND FIXED 2.00 RETURN_PRORATA，CHARGEBACK FIXED 100，结算 T+2 AE_BUSINESS_DAYS UTC 86399）→ submit（maker A）→ approve（checker B；同时验证 maker=checker 被拒）→ schedule（effectiveFrom=now+1 分钟）→ 等待后 activate → 校验 `CommercialTermVersionActivated` 到达。
5. 命中：POST /commercial-prices/v1/resolutions（USD、CARD、VISA/CREDIT/DOMESTIC → 命中具体画像；FUNDING_TYPE 缺失 → 422 PRICING_FACTS_INCOMPLETE；AMEX → 命中兜底）；GET /commercial-prices/v1/{priceId}。
6. 费率卡：GET /rate-cards/v1?clientId=&asOf=now&currency=AED → 结构核对（开通项、币种分块、组件、结算、版本）。
7. 换版：新建 v2 复制 v1、改 CAPTURE 为 2.2%、走审批排期激活；再次命中 → v2；用 v1 生效期内的 contextAsOfTime 命中 → 仍 v1。
8. 解析：POST /checkout-context/v1/resolutions → 预期 503 OWNER_UNAVAILABLE（client-master 未启动），记录。
9. 清理：停进程；报告中说明 `mor_commercial_lineb` 留有冒烟数据（由主会话决定是否清理）。
