## P1 规则集（修改）

```
风控管理 / 规则配置
┌──────────────────────────────────────────────────────────────┐
│ 风控点 [支付尝试 ▾]   规则集编码 [____]  状态 [全部 ▾]  [查询] [重置] │  ← 下拉来自创作上下文 supportedPoints
├──────────────────────────────────────────────────────────────┤
│ 规则集名称 │ 编码 │ 当前版本 │ 状态 │ 更新时间 │ 操作 ▾            │
└──────────────────────────────────────────────────────────────┘
```

- 风控点写入 URL（`pointCode`），刷新保持；默认取 URL，否则结账准备（兼容现有链接）。
- 新建/编辑/只读详情均按所选风控点加载创作上下文：字段候选、运算符、终态动作（支付点为放行/审核/拒绝，无附加动作区域）。
- 结账点保持现状（含旧格式只读视图）。
- 删除返回 `RISK_RULE_SET_IN_USE` 时，提示“该规则集被生效中或影子运行中的执行发布引用，不能删除。请先在【执行发布】中替换”，并提供跳转链接。

```
去重主体 [消费者 ▾]          ← 仅“不同主体数”显示，且不得与统计主体相同
时间窗口 (•)10分钟 ( )1小时 ( )1天 ( )7天
计入本次 [ ]                 ← 仅 次数/金额合计 且 事件=支付尝试评估 时可勾选
口径预览：同一卡指纹 10 分钟内的支付尝试评估次数（不含本次）

```

```
来源类型 [名单命中 ▾]
```

- 详情页：Risk 不回显统计参数（R-Q3 已决定不做），详情显示来源类型并提示“统计参数以创建时为准，不可修改；口径请参考变量名称与说明”。

## P4 风控名单（新增，`/risk/lists`）

```
风控管理 / 风控名单                                              [＋ 新建名单]
┌──────────────────────────────────────────────────────────────────────┐
│ 名单编码        │ 名单名称      │ 主体类型 │ 用途   │ 状态 │ 操作        │
│ BLOCK_IP        │ 拦截 IP 名单   │ IP 地址  │ 拦截   │ 启用 │ 成员         │
│ ALLOW_CONSUMER  │ 白名单玩家     │ 消费者   │ 放行   │ 启用 │ 成员         │
└──────────────────────────────────────────────────────────────────────┘
空状态：暂无名单。名单用于“名单命中”变量，命中后如何处置由规则决定。
```

新建名单弹窗：名单编码（大写字母开头，≤64）、名称、主体类型（6 选 1：Client、运营主体、消费者、IP 地址、卡指纹、卡 BIN）、用途（拦截 / 放行，提示“仅用于展示”）。创建后不可修改。

成员页（点“成员”进入，`/risk/lists?listCode=BLOCK_IP`）：

```
← 风控名单 / BLOCK_IP · 拦截 IP 名单 · IP 地址                         [＋ 加入成员]
┌──────────────────────────────────────────────────────────────────────┐
│ 主体值 [________]（精确匹配，按原值查询）  状态 [生效 ▾]  [查询] [重置]     │
├──────────────────────────────────────────────────────────────────────┤
│ 主体（脱敏） │ 状态 │ 生效时间            │ 原因        │ 添加人 │ 操作   │
│ 203.0.***    │ 生效 │ 10-15 10:00 ~ 永久  │ 卡测试来源   │ op01   │ 失效   │
│ 198.51.***   │ 已失效│ 10-01 ~ 10-08       │ 误封 · op02  │ op01   │ —      │
└──────────────────────────────────────────────────────────────────────┘
```

- **主体值只显示 Risk 返回的 `maskedSubjectKey`**；查询框输入的原值不写入 URL，提交后清空，不保存到浏览器存储。
- 加入成员弹窗：主体值（输入后提交即清空，按主体类型给格式提示，如 IP 地址、6～8 位 BIN）、原因（必填 ≤500）、生效起止（可选，留空=立即生效 / 永久）。重复加入（409）提示“该主体已在名单中生效”。
- 失效确认：必填原因；失效后不可恢复，需要时重新加入。
- 无“维护名单”权限：隐藏新建、加入、失效按钮。


- 风控点下拉只列支持执行发布的点（本期仅支付尝试）；选结账准备时显示“结账准备暂不支持执行发布”。
- 未知状态原样显示编码（灰色标签）。
- “以此版本新建”＝回滚：预填该发布的决策流版本，走完整的校验 → 影子 → 激活流程；不提供“重新激活”。

新建发布弹窗：决策流（本点流程列表）→ 流程版本（历史版本，默认当前版本）→ 创建。规则集未冻结等 Risk 拒绝原因原样展示，并提示“请先在规则配置中冻结引用的规则集版本”。

详情（抽屉或子页 `?releaseId=`）：

```
R-0004 · PAY_MAIN #6 · 支付尝试 · TEST
 ①创建 ✓ ──── ②校验 ✓ ──── ③影子运行 ●进行中 ──── ④激活
┌ 静态检查（8 项）────────────────────────────────┐
│ 引用完整性 ✓  条件结构 ✓  条件类型 ✓  特征依赖 ✓   │
│ 处理器摘要 ✓  动作参数 ✓  终态动作 ✓  系统义务 ✓   │  失败项显示错误摘要
└──────────────────────────────────────────────┘
┌ 影子运行（基线 R-0003）──────────────────────────┐
│ 样本 186 / 200   状态：运行中…（每 3 秒刷新）        │
│ 放行→审核 4   放行→拒绝 2   [拒绝→放行 1]  [认证要求变化 7] │ ← 后两项 >0 时红色醒目
│ 特征缺失 0   失败 0   超时 0   P95 38ms  P99 71ms  技术门槛：通过 │
└──────────────────────────────────────────────┘
操作：[校验] [发起影子运行 样本数 200] [激活]
```

- 按钮按状态显示：DRAFT→校验；SHADOWING 且有生效发布→发起影子运行（样本数 1～2000，默认 200）；SHADOWING 且（无生效发布，或最近影子运行完成且失败/超时为 0）→激活；REJECTED→只读并显示失败项。
- 影子运行中每 3 秒轮询详情，离开页面停止；超过 10 分钟提示“仍在运行，可稍后刷新”。
- 激活确认弹窗：

```
┌ 激活执行发布 R-0004 ─────────────────────────────────┐
│ 激活后立即替换当前生效发布 R-0003，对新的支付评估生效。   │
│ ┌──────────────┐ ┌──────────────┐                     │
│ │ 拒绝→放行  1  │ │ 认证要求变化 7 │  ← 大号数字，>0 红色   │
│ └──────────────┘ └──────────────┘                     │
│ 放行→审核 4 · 放行→拒绝 2 · 失败 0 · 超时 0 · 样本 200   │
│ [ ] 我已查看影子差异并确认激活   ← 两项任一 >0 时必须勾选  │
│                                     [取消] [确认激活]   │
└──────────────────────────────────────────────────────┘
首次发布（无基线）：显示“这是该风控点的首个发布，没有影子对比，激活后立即对支付评估生效”，需勾选确认。
```

- 激活前置不满足（400 `BUSINESS_CHECK_FAILED`）原样显示 Risk 原因，不关闭弹窗。
- 无“创建与校验发布”权限隐藏新建/校验/影子按钮；无“激活发布”权限隐藏激活按钮。

## 通用状态

| 状态 | 表现 |
|---|---|
| 加载 | 表格骨架 / Spin |
| 空 | 各页给出说明文案（见上） |
| 403 | 沿用现有：刷新授权，菜单不可见 |
| 409 | 名单重复、规则集被引用、并发冲突：明确中文提示 |
| 502/503 | 沿用现有错误提示与重试按钮 |
