## 状态

| 状态 | 表现 |
|---|---|
| 初始 | 只有查询条与说明“输入支付尝试 ID 或评估 ID” |
| 加载 | 结果区骨架屏；查询按钮禁用 |
| 输入格式错误 | 输入框下提示“请输入 1～19 位数字”，不发请求 |
| 未找到（404） | 空状态“没有找到该评估” |
| 无权限（403）/ 其他错误 | 沿用现有错误提示组件，显示 Request ID |
| 影子评估 | 结论卡片标“影子评估”，显示基线评估链接；影子分区不显示 |
