# card：BIN 库页面重设计与号段列表

状态：阶段 1—8 完成 · 登记 2026-10-27 · 交付记录见 [delivery.md](./delivery.md)

## 1. 背景

运营控制台“卡 BIN 库”页面（`/card-bin-library`，[2026-10-22 需求](../../20261022/card-BIN库与卡属性/requirement.md)交付）存在两个问题：

1. **看不到数据本身。** 页面只能管理版本（导入 / 激活 / 回切）和按单个 BIN 查询，运营无法浏览某版本里有哪些号段、卡组织 / 发卡国分布如何。Card 也没有提供号段列表接口（现有接口：版本列表 / 详情 / 错误行 / 导入 / 激活 / 激活历史 / 单 BIN 查询）。
2. **页面布局杂乱、设计感差。** 一屏堆了说明长句、4 张摘要卡（含 18 位操作人 ID 换行）、独立的 BIN 查询条、版本表、右侧详情和激活历史，主次不清，和 Stripe 一类控制台差距明显。

## 2. 目标

参考 Stripe Dashboard 的风格（克制的排版、单一主面板、轻量标签与筛选、表格为主、少量文案）重做该页面，并让运营能直接浏览和筛选 BIN 号段数据。

## 3. 本期范围

| # | 内容 |
|---|---|
| S1 | **号段列表（新能力）**：按版本分页浏览号段，默认当前生效版本，可切换到任一已校验通过（VALID / ACTIVE / RETIRED）的版本；列：BIN 前缀、卡组织、借贷记、卡等级、卡产品、发卡国、发卡行。 |
| S2 | **号段筛选**：BIN 前缀（输入 1～8 位数字做前缀匹配，同时替代原独立的“BIN 查询”条：输入 6～8 位时另外给出最长前缀匹配结果）、卡组织、借贷记、发卡国。 |
| S3 | **页面结构重设计**：页头 = 标题 + 生效版本徽标 + 右侧“导入新版本”；下方两个页签 **号段数据**（默认）/ **版本**（含计数徽标与待激活提示）；去掉 4 张摘要卡和长说明，关键事实压成页头一行元信息。 |
| S4 | **版本页签重设计**：版本列表 + 选中版本详情（统计、校验错误行、激活 / 回切操作在详情底部操作栏），激活历史并入版本详情或时间线，不再单独堆放。 |
| S5 | 导入、激活 / 回切弹窗沿用现有行为，仅按新视觉统一样式。 |
| S6 | 操作人显示：有姓名时显示姓名，否则显示截断 ID（悬停看全）；不再整串 18 位换行。 |
| S7 | 中英文文案、1440 与 390 宽度可用。 |

## 4. 本期不做

- 不改变 BIN 库导入、校验、激活、回切的业务规则与状态机；不改 Payment / Risk 对卡属性的消费。
- 不做号段的单条新增 / 编辑 / 删除（数据仍只能整版导入）。
- 不做号段导出、跨版本差异对比（可列为后续）。
- 不改数据库表结构；只读查询复用现有 `uk_card_bin_range (version_id, bin_prefix)` 索引。

## 5. 验收标准

### 功能验收

| 编号 | 标准 |
|---|---|
| AC-1 | 打开页面默认显示当前生效版本的号段列表，分页正确，总数与版本号段数一致。 |
| AC-2 | 可切换到任一 VALID / ACTIVE / RETIRED 版本查看号段；VALIDATING / INVALID 版本不可选并说明原因。 |
| AC-3 | BIN 前缀、卡组织、借贷记、发卡国筛选组合生效；输入 6～8 位数字时显示该 BIN 的最长前缀匹配结果（与原单 BIN 查询结果一致），非数字输入即时提示且不发请求，不接受完整卡号（>8 位）。 |
| AC-4 | 无生效版本、版本号段为 0、筛选无结果分别有明确空状态；接口失败显示错误与 requestId 并可重试。 |
| AC-5 | 版本页签保留原有全部能力：状态筛选、版本详情、校验错误行、导入、激活、回切、激活历史；无维护按钮权限的账号看不到写操作。 |
| AC-6 | 号段列表接口只读，仅 operations-console-bff 可调用，经 Gateway 路由并受控制台资源权限（沿用 `OPERATIONS_CARD_BIN_LIBRARY`）约束。 |

### 视觉 / 交互验收

| 编号 | 标准 |
|---|---|
| UV-1 | 页面以单一主面板 + 页签组织，首屏无摘要卡堆叠和长段说明；生效版本、号段数、最近激活以页头一行元信息呈现。 |
| UV-2 | 表格为主视觉：行高、字重、灰阶层级参照 Stripe；卡组织显示品牌标识，发卡国显示国旗 + 代码 / 名称（复用参考数据国家控件）。 |
| UV-3 | 筛选为表格上方的一排轻量筛选 chip（Stripe 风格“+ 卡组织”式），已选条件可一键清除。 |
| UV-4 | 待激活版本以版本页签计数徽标 + 页头提示点提示，而不是独立卡片。 |
| UV-5 | 中英文、1440 / 390 下无溢出、无原始 i18n 键；浏览器实测通过。 |
