# commercial 价格组件表格维护

> 状态：阶段 1–8 完成（2026-10-20），已部署 mor-test，已本地提交（未推送）。确认记录见 [delivery.md](./delivery.md)。

## 1. 背景

「商务 → 价目 → 编辑价格」抽屉（`operations-console-web/src/commercial/PriceEditorDrawer.tsx`）里，每个组件是一张 3 列网格表单卡片：组件代码、类型、计费事件、计算基数、退款处理、金额币种，再按类型加费率 / 上下限或固定金额或阶梯字段，外加「删除组件」按钮。一条收单价格通常有 6 个组件（CAPTURE / SALE 的百分比与固定额、退款费、拒付费），一个版本 11 条价格就是 66 张卡片，字段标签与帮助文字大量重复，屏幕上一次只能看到一两个组件，无法横向比较。

## 2. 目标

组件改为每行一个组件的可编辑表格，一条价格的全部组件在一屏内看完、横向可比；价格卡片本身可折叠，折叠时显示一行摘要。保存行为、请求体与 commercial 校验不变。

## 3. 范围

**包含**

1. **组件表格**：每行一个组件，列为「组件代码 · 计费事件 · 类型 · 计算基数 · 费率 · 固定金额 · 最低 · 最高 · 退款处理 · 操作」，单元格内直接编辑；类型决定哪些列可填，不适用的列显示「—」不可编辑。
2. **阶梯组件**：费率 / 固定金额列显示「N 档 · 整笔适用 ▾」，点开在该行下方展开档位子表（下界、上界、费率、固定金额、移除），连续性提示保留。
3. **金额币种列去掉**：组件币种只能等于价格币种（commercial 激活校验），页面不再让人填；保存时按规则自动带上：固定额、阶梯或填了上下限的百分比组件取价格币种，其余为空。
4. **费率按百分比输入**：输入 `2.2` 显示「2.2 %」，保存换算为 `0.022`；读回时反向换算。阶梯档位的费率同样处理。
5. **中文选项**：计算基数、退款处理、阶梯基数 / 模式的下拉显示中文名（代码作为副文字），例如「交易总额 GROSS_AMOUNT」「按比例退 RETURN_PRORATA」。
6. **行操作**：复制本行（插在下一行，组件代码追加 `_COPY` 待改）、删除（只剩一行时不可删）；表尾「添加组件」。
7. **价格卡片可折叠**：卡片头一行摘要「价格 1 · AE001 · AED · CARD_VISA_CREDIT_DOMESTIC · 优先级 1 · 6 个组件」；展开后 OE / 币种 / 优先级 / 画像一行，结算四字段一行，下面是组件表格。超过 3 条价格时默认全部折叠，否则默认展开；校验失败的价格自动展开并滚动到第一处错误。
8. **校验提示**：单元格校验失败时红框，错误文字显示在该行下方（不撑开列宽）。

**不做**

- 不改 commercial / BFF 接口、请求体结构与保存语义（仍是整体替换）。
- 不改价格集合的业务规则（画像、OE、优先级唯一性等）与排期 / 激活校验。
- 不做批量导入 / 导出、跨价格批量改费率（可另立需求）。
- 不改 `commercial/commercial.ts`、`commercial.css`（有其他需求的未提交改动）：新逻辑放新文件。

## 5. 验收标准

**功能**

| 编号 | 验收 |
|---|---|
| AC-01 | 打开已有版本，组件逐行显示，值与原抽屉一致；不改任何值直接保存，提交的请求体与改版前逐字段相同（含组件币种）。 |
| AC-02 | 类型切换：百分比可填费率 / 最低 / 最高；固定额只可填固定金额；阶梯只可编辑档位；不适用列为「—」且保存时为空。 |
| AC-03 | 费率输入 `2.2` 保存为 `0.022`；读回 `0.025` 显示 `2.5`；最多 8 位小数（对应接口 10 位）。档位费率同规则。 |
| AC-04 | 组件币种自动推导：固定额、阶梯、填了上下限的百分比为价格币种，其余为空；改价格币种后无需逐行修改。 |
| AC-05 | 复制行、删除行（剩一行时禁用）、添加组件、阶梯行展开 / 收起档位、添加 / 移除档位均可用，档位连续性提示与原来一致。 |
| AC-06 | 价格卡片折叠 / 展开，摘要内容正确；> 3 条价格默认折叠；保存校验失败时出错的价格自动展开并定位到第一处错误。 |
| AC-07 | commercial 返回的 Owner 错误（如 detail「同一 OE 与币种下优先级重复」）照常显示在抽屉顶部。 |

**视觉 / 交互**

| 编号 | 验收 |
|---|---|
| AC-08 | 抽屉宽 1080 时组件表格不出现横向滚动；更窄时滚动只在表格内部。 |
| AC-09 | 6 个组件的价格展开后在 1080 × 900 视口内能完整看到组件表格。 |
| AC-10 | 单元格错误红框 + 行下方错误文字，不撑开列宽；选项中文名 + 代码副文字；风格与现有商务页一致。 |
