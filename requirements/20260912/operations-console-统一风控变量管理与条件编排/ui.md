阶段3设计稿。沿用现有Operations浅色、蓝色强调、Ant Design组件和React Flow画布；没有引入新UI框架。使用Pencil在[Operations原设计文件](../../../operations-console-web/docs/design.pen)追加RCO-19画板，原40张画板保留，Checkout文件未修改。

## 变量管理

- `/risk/variables`列表；新增来源选INPUT/CONSTANT/COLLECTION；NODE_OUTPUT可查看但不能伪造定义。系统管理集合的成员只读。
- 按`/risk/variables/:code`详情与`/edit`编辑、`/members`成员、`/references`使用关系组织浏览器历史。列表筛选/分页留URL，详情/编辑用push导航，浏览器后退回实际前页；不增加“返回来源页/返回列表”按钮。
- readonly与edit复用表单结构；readonly字段不可改，无保存/提交。系统结构不可改的字段明确只读，不给用户一个提交后才拒绝的编辑框。
- 列表操作用现有Dropdown，鼠标悬停/点击和键盘均可展开；按权限与系统管理属性裁剪按钮。集合追加“成员”；删除为红色且确认框写明变量名称，真实删除由Owner复核使用关系。
- 名称/说明/常量值/状态一起保存。创建集合先保存定义再维护成员；页面明确空集合已创建，不在失败时伪装整体未创建。

## 同一套条件编辑器

两侧上方统一“变量 / 常量”切换。变量选择器搜索名称/编码，按来源分组，显示类型；结果来自N02，无硬编码默认国家、行业或matched。左侧常量可独立选择类型/金额单位，右侧控件按运算符与兼容类型约束。

- EQ等：两侧标量；IN/NOT_IN右侧选择集合变量或输入同类型literal集合；BETWEEN显示下界/上界两控件；一元运算隐藏右侧。
- 变量引用显示变量名称及编码，可展开常量当前值/集合数量和成员。直接常量标为“常量”，不显示成共享变量。
- 不把变量的当前金额复制进输入框成为literal；切换来源时显式重选值，不能悄悄保留另一种来源的残留字段。
- 数字金额显示币种来源。相同NUMBER但量纲/币种不一致时原位错误，不静默换汇。
- 流程仅当前规则集节点出线可选NODE_OUTPUT。结果选择器显示集合中的PASS/REVIEW/REJECT标签，保存真实ALLOW/REVIEW/DENY；未选值不默认PASS。
- 延续圆角折线、浏览器返回；点击画布空白取消节点/连线选择并隐藏整个右侧配置区，保留草稿。没有恢复上期已删除的底部说明块或额外“返回”按钮。

## 关键异常和草稿状态

| 状态 | 页面反馈与恢复 |
|---|---|
| 目录加载中 | 控件骨架/加载状态，未取得数据前不允许选择伪造默认值 |
| 变量库为空 | “暂无可用变量”；有维护权限显示创建入口，无权限给出空态，不补固定9字段 |
| 搜索无结果 | “没有匹配变量”；可清空搜索，不改当前已选引用 |
| 请求失败 | 内联“加载失败，重试”；保留草稿，旧选项标记待核验 |
| 变量停用/缺失 | 显示原名称或编码、状态和可定位错误；历史仍可读，不能保存新引用 |
| CAS冲突 | 显示已被修改，提供重新读取；不自动覆盖本地未保存内容 |
| 成员重复/格式错误 | 标明行号和值；显示有效/重复/错误数量；修正后才能合并，服务端再独立校验 |
| 后端保存失败 | 定位到条件/操作数/成员；保留输入、当前焦点和图位置 |
| 未保存返回/离开 | 复用现有离开确认；只在内存保存草稿，不写敏感内容到本地持久存储 |
| 历史动态变量 | “当前值”，附查询时间；没有保存当时值/执行用值的假展示 |

## 设计检查

每个新画板完成后使用Pencil截图检查，并在导出前检查新画板的裁剪/越界和placeholder状态；具体检查结果记录在delivery.md与当前台账。静态设计不等于实现了点击、焦点刷新或真实权限验证，这些在研发/综合回归阶段验证。
