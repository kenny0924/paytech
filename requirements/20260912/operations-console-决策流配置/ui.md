## 1. 列表、路由和返回

菜单“风控管理 / 决策流”进入 `/risk/decision-flows`。列表 query 保存 pointCode/flowCode/keyword/page/size；React Router history 记录真实导航，不用 replace 连续覆盖整个导航栈。

图工作区使用同一路径的 view=create/edit/detail/history/version/legacy 参数，加所需 flowId/flowVersionId/maxVersionNo/pointVersionId。详情和历史版本直接进入只读图；历史面板显示准确版号、保存人 ID、时间和变更原因，点击版本是一次可返回的导航。仅新建/编辑有保存控件；本期没有发布、冻结、TEST Candidate 或试运行入口。

列表行操作通过“操作”按钮点击或悬停展开；详情、编辑、历史版本按相应 READ/SAVE 权限展示，删除为红色且需 DELETE 权限。确认弹窗明确写“删除整个决策流「名称 / 编码」？历史版本保留，规则集不受影响。”成功回到原筛选页；删除最后一条导致空页时退一页。没有单版本删除。

点击流程规则集的“查看此版本规则”进入 `view=rule-reference&sourceType=FLOW_VERSION&sourceVersionId=...&nodeKey=...`，复用原只读规则工作区，从 N09 取准确内容。旧规则集发布引用页的 Point Version 新增“查看编排”，进入 view=legacy；不新增 Candidate 操作。

原因引用页新增“来源”列，分别显示规则集或决策流；FLOW_END 点击进入该准确历史流并选中节点，即使流程已删除也只读显示。原规则字段不冒充流程字段；scope 的 ALL/CURRENT/HISTORY/DELETED 保持原含义。

全程没有页面返回按钮。浏览器 Back/Forward 恢复上一层与列表查询；节点/线选中及面板内开关不额外写入每一次历史记录。编辑离开前已有未保存保护仍生效，取消离开继续留在原图。

## 2. 图形编辑和条件

- 只有 START/RULE_SET/END 三类节点。节点名称、准确规则版本、规则数始终可见；紧凑模式不只剩序号。
- 新建默认一条开始到待配置结束的直连，结束决定为空；用户可添加规则集、替换连线、显式选结果。没有隐式默认 ALLOW。
- 选择规则集时使用同点根列表及准确版本历史；编码可精确搜索，列表分页浏览。只展示合法新选择 DRAFT/FROZEN；已保留 RETIRED 显示提示，不自动追随最新。输入合同不匹配或删除引用阻止保存，允许用户替换。
- 点击连线及标签开侧栏：来源/目标、名称、类型、条件与同源出口顺序。条件只能用“当前决策点输入”或“本节点是否命中”；布尔值用是/否控件，金额使用十进制输入，不显示脚本/SQL/JSON。
- 出口列表通过上移/下移调整并立即重新编号 1..N；ELSE 固定显示在最后且不能拖进条件区。画布位置、连线创建时间与优先级无关。同源 UNCONDITIONAL 与条件+ELSE 两种模式切换，若会删除已有条件，先在面板内说明并确认丢弃本地配置。
- END 显式选择 ALLOW/REVIEW/DENY。DENY 选原因并可调整文案；切换为其他决定时清空不适用的原因字段，不留下隐藏数据。原停用原因仅在精确原节点/原 Code/原文案保留时可继续保存。
- 删除节点同步删除其入线/出线，不自动重连前后。删除线可能暂时产生不完整结构，允许本地继续编辑，保存必须修复。开始节点不能复制，不能通过键盘产生多个开始；Owner 仍需校验直接 API。
- 缩放、平移、选中只是查看状态；节点坐标按整像素保存。不存画布 zoom/viewport 或图形库内部字段。

已有 ALLOW/REVIEW/DENY 仍立即结束整个流程。没有最终决定才走出线；错误不是未命中，不能沿 ELSE 放行。画板中的币种、流程名称、版本、人员和时间全部为合成示例，不是已配置的运行策略。

## 3. 规则动作可选与只读

原规则编辑器统一显示必填的匹配条件和“命中后的动作（可选）”，不新增规则类型、处理模式、模式切换或额外确认弹窗。沿用已有最终决定选择和附加动作编辑：最终决定可清空，附加动作逐项添加、编辑或删除，最多一个最终决定的约束保持。最终决定未选、附加动作列表为空时直接保存；一行说明“未配置动作时，提供命中结果，由流程连线决定下一步”。

列表摘要显示实际配置的决定/附加动作；均为空则显示“未配置动作”，不展示“仅判断”类型或类型统计。当前详情和历史按保存的动作回显。空动作使用 CONFIGURATION 中既有 action=null、additionalActions=[]，不新增字段，也不新增保存步骤；原 LEGACY 或损坏动作仍须拒绝。旧 Freeze 不接受含未配置动作规则的版本；已有终态与附加动作行为保持。

当前详情、历史、旧点投影、引用规则全部只读。可选择节点/线查看侧栏、平移、缩放；禁用节点拖动、连线/重连、删除、输入、粘贴创建等修改事件及快捷键。只读侧栏使用文本，不保留可编辑输入框伪装禁用。无保存/删除按钮。

已退休引用展示准确版号和当前资格提示；已删除引用仍展示保存的名称与内容，并说明新保存前需替换。字典名称/默认文案变化不重写历史。旧顺序 Point Version 标明“原顺序配置 · 只读”，保留原默认决定；不冒充新的 Flow 身份。

## 4. 全部必要状态

| 状态 | 页面行为 |
|---|---|
| 首次空列表 | “暂无决策流”；有 SAVE 权限时提供新建，不展示虚假示例数据 |
| 搜索无匹配 | “没有匹配的决策流”，保留筛选并提供重置 |
| 加载中 / 加载失败 | 骨架与就地重试；失败不显示空列表冒充成功，不清空已有编辑 |
| 初始图未完成 | 保存禁用并显示缺少的基本信息/节点决定；可继续编辑和静态校验 |
| 校验通过 | “配置校验通过”；说明仅静态校验，不显示已运行/已生效 |
| 校验失败 | 面板问题卡，点击居中并高亮相应节点/线，字段错误定位侧栏；同一断线造成的级联不可达提示合并，避免重复轰炸 |
| 编辑修复后 | 先前校验结论过期；允许重新校验，保存仍由 Risk 完整重证 |
| 保存成功 | 显示新配置版本号并更新 base/CAS，清理 dirty；不跳发布页、不激活 |
| 网络/保存失败 | 保留图及表单，显示安全 Problem 与 requestId；重试同一命令复用原 Key，编辑请求后才产生新 Key |
| 并发冲突 | 明确有人更新，保留本地内容；用户选择重新加载最新时提示会丢弃本地编辑，不静默覆盖或自动合并 |
| 删除/引用资格变化 | 显示具体对象及原因；引用错误执行一次静态校验帮助定位，用户主动替换版本 |
| 未保存离开 | 浏览器返回、菜单离开及关闭/刷新按既有 guard 提醒；取消则保留输入 |
