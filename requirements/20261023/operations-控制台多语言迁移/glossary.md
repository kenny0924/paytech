## 4. 写法约定

- 菜单、页面标题、按钮、表头用 Title Case（Save Draft、Created At）；提示句、说明、校验信息用句首大写（"Enter a reason."）。
- 时间列统一 `… At`（Created At、Updated At），时间段用 `… Time`。
- 数量句用 ICU 复数：`{count, plural, one {# record} other {# records}}`。
- 不翻译编码、枚举原值、ID、币种代码、MID、BIN 等技术值。

## 5. 研发期间的裁决补充（2026-10-23）

各模块研发中的用词裁决见 [tasks/english-decisions.md](./tasks/english-decisions.md)，与本表冲突时以裁决为准，主要包括："驳回 / 已驳回"统一为 Reject / Rejected（"退回修改"仍为 Return for Changes）；"内容摘要"为 Content Hash；授权语境"放行 / 拒绝"为 Allowed / Denied；租户安全状态"已暂停"为 Suspended；滚动保证金为 Reserve / Rolling Reserve；失败提示统一为 "Couldn't …"。
