# 对外金额使用主单位十进制字符串

用户要求：对外不再用 1000 表示 10.00，统一采用 10.00 这种金额格式，并直接调整现有实现。

- 请求与响应的金额为币种主单位 JSON 字符串；例如 USD `"10.00"` 表示 10 美元。
- 输出保留币种规定的小数位，不把 JPY 或 KWD 强制当作两位小数；不因此启用新的业务币种。
- 金额值、数据库记录、历史 Hash 和第三方渠道原协议保持原有含义。
- 验收覆盖主单位不缩放、输出补零、零/负数、不同币种、超精度拒绝以及最大合法金额的 JSON 往返。
- 后续用户确认删除 Commerce 的 MoneyValue，直接使用公共 Money；Commerce 的正负、数据库范围、数量及整行优惠规则保留在本服务，现有业务错误码、历史快照与接口字段结构保持。

现行规则由[开发规范](../../../agent-docs/DEVELOPMENT_CONVENTIONS.md#21-对外金额格式)拥有，差异与边界见[技术说明](technique.md)。
