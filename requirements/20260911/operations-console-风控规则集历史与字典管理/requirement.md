## 1. 目标与已确认范围

Operations 人员能够查看一个规则集的全部已保存版本、理解它被哪些发布引用，并通过统一的原因和标签目录完成规则配置。查询始终只读，保存继续产生新的不可变业务版本。

| 功能 | 已确认目标 |
|---|---|
| 当前详情 | 列表“详情”进入与编辑器布局一致的只读页面；默认加载最新保存配置 |
| 历史版本 | 列表操作增加“历史版本”，版本倒序分页展示；点击查看打开所选版本的只读页面 |
| 发布引用 | 提供引用关系图与明细，呈现发布、决策点版本、规则集版本的真实引用，区分环境及发布状态 |
| 拒绝原因字典 | 查询、新增、编辑、启停、被规则引用查询；包含稳定编码、名称、内部说明、默认内部文案和状态 |
| 主体标签字典 | 查询、新增、编辑、启停、被规则引用查询；包含稳定编码、名称、业务含义和状态，使用场景由人工判断 |
| 编辑器接入 | REJECT 选择原因后带出默认内部文案，允许规则内调整；主体标签从字典选择，Risk 校验可选资格 |

字典编码创建后固定且不复用；停用后不能新选。修改字典不改写已保存规则，旧代码和消息仍以保存时内容为准。文案暂与原因一起维护，不单独建设文案字典；它仍是内部说明，对外提示继续遵循消费方合同。

## 2. 保持的业务边界

- 主列表一个规则集一行，整体删除和永久保留编码不变；任一版本被当前 ACTIVE 发布引用时仍禁止删除。候选、已失效历史引用以及 FROZEN 本身不构成使用中。
- 本次历史查看不等于恢复、编辑或覆盖旧版本。列表“编辑”仍基于最新保存配置，沿用并发及命令幂等约束。
- 只建设配置功能，不新增评估、真实冷却/打标签、主体标签实例查询、Shadow、审批、发布激活或实际交易调用血缘。Candidate 操作页面继续隐藏。
- 字段、运算符、动作和主体绑定仍由工程能力定义；字典管理不能注册一个没有输入/执行语义的新能力；标签本期不设主体类型关系或字段，不按主体类型限制标签选择。绑定可选性继续由 Risk 按决策点输入提供，不在 Web/BFF 写死 Client/Consumer。
- 国家、币种、行业、MCC 等公共目录不在本次重建。名称搜索、复制、人员显示优化、通用视觉优化、冻结入口清理、版本比较与从历史恢复均不纳入。
- 沿用原接口版本，新接口默认 v1；Java 类型不含协议版本后缀，业务版本字段继续保留。

## 3. 验收标准

以下编号将已确认功能整理为可测试结果。用户已在阶段 3 评审中明确去掉两张辅助表及对应约束；保留原规则集历史/回放，修订后的精确判据见 [data.md](./data.md)；接口、数据及 [Pencil 页面](./ui.md)已由本次“继续”确认。

| 编号 | 功能验收 |
|---|---|
| AC-01 | 当前详情与编辑共用页面结构；详情展示完整基本信息、规则、条件、决定、原因文案及附加动作；无保存按钮，无新增/修改/删除/排序入口 |
| AC-02 | 历史列表按业务版本倒序分页，显示版本号、保存人、保存时间、变更原因；包含已退役版本，不改变主列表的单行与总数语义 |
| AC-03 | 历史查看按明确的版本标识加载，刷新仍显示该版本；不会切换到最新配置，也不会因为当前字典停用而丢失历史代码、文案或参数 |
| AC-04 | 只读用户能查询和切换规则、展开条件、查看基本信息；只读页面不会发送写命令，写接口仍由服务端逐请求授权 |
| AC-05 | 列表→历史列表→版本详情与列表→当前详情保留真实浏览器前进/回退、筛选和分页；只读查看不产生未保存提示，真实编辑与未决命令保护保留 |
| AC-06 | 发布引用图和明细以真实 Risk 关系为准，显示发布身份、环境、状态、所引决策点版本及规则集版本；可进入所引规则集版本的只读页面；空结果与查询失败分别表达 |
| AC-07 | 当前 ACTIVE、候选及历史非活动引用可明确区分；引用全体版本，旧版正在使用也能说明删除被阻止的原因；图不计算规则命中，不增加激活操作 |
| AC-08 | 拒绝原因字典完成分页查询、新增、编辑、启停及被规则引用查询；编码固定不复用，文案为内部用途 |
| AC-09 | 主体标签字典完成分页查询、新增、编辑、启停及被规则引用查询；以名称/说明表达人工判断的使用含义，不配置标签适用主体关系或限制 |
| AC-10 | REJECT 新选原因后自动带出默认文案，可在该规则内修改；标签不能任意输入新代码绕过字典；Risk 对保存做权威校验，不能只依靠下拉框 |
| AC-11 | 已保存版本的内容及 Hash、原成功命令回放不随字典变化而改变；旧手工代码、停用项和旧空消息均可原样查看，新增/编辑保存的兼容口径按阶段 3 批准合同验收 |
| AC-12 | 字典配置命令有独立可授予权限、编码唯一和版本校验；网络异常由人工刷新确认当前结果，不增加字典回执或历史响应回放；有规则配置权限但无字典维护权限的人员仍可读取必要选项；越权不产生 Risk 变更 |

视觉/交互验收同时覆盖：当前详情与历史详情和编辑器的结构一致；只读页的查看操作仍可用；历史版本标识明确；图和明细相互对应；字典空态、无权限、停用项、失效选择和加载失败可辨认；键盘、触屏及窄屏能够完成上述功能。具体布局和图交互以已确认的阶段 3 页面合同为准。
