## 2. 页面入口与导航

主菜单增加 `/risk/rejection-reasons`（OPERATIONS_RISK_REJECTION_REASONS）和 `/risk/subject-tags`（OPERATIONS_RISK_SUBJECT_TAGS），在风控管理下按“规则配置、拒绝原因、主体标签”排序，后两项依赖对应 Resource 可见。

规则配置保持 `/risk/rule-configuration`，扩展现有 Query 路由状态：

- `view=list/detail/edit/create/history/version/references`。detail/edit 沿用当前配置选择方式；history/references 带根 ruleSetId，version 另带 ruleSetVersionId、pointCode、ruleSetCode 并校验归属。
- 主列表的 page/size/筛选与历史列表的 historyPage/historySize/maxVersionNo 分开保存；引用页 refPage/refSize/environmentCode/releaseStatus/refVersionId 分开保存。
- 用户点击进入子页用 push；初始化/非法 URL 的规范化用 replace。浏览器返回使用真实 history；页面“返回列表/返回历史版本/返回引用关系”使用受控来源状态恢复筛选，不跳默认审计页，不接收任意外部 returnUrl。
- 从图或字典引用打开指定版本后，返回到原查询的页码/过滤。直接访问版本详情没有来源时，返回该根历史列表；根已删除则显示不可访问并给出回主列表入口。
- 只读页面切换规则、折叠、分页不产生 dirty；真实编辑、关闭有修改的抽屉及原规则集未决命令仍受离开保护约束；字典未知结果按本稿人工刷新确认。失败/取消不丢用户输入。

## 3. 只读与编辑模式

`RuleSetEditor` 明确 `mode=read|edit`，不将现有 disabled 直接当成查看模式。只读不构造保存 Payload，不显示添加规则/条件/组/动作、拖拽、启停开关、删除、恢复默认或保存条；启停作为文字状态。仍可切换规则、展开条件、查看完整消息、基本信息和规则描述。保存人只显示 Account ID，本期不新增人员详情聚合。

当前详情按当前管理入口读取；历史详情按 URL 精确 ID 读取，不因为加载期间产生新版本而跳到最新。读取不要求 SAVE 权限；Authoring Context 或字典停用/不可用不应抹掉已保存字段。历史不伪造“当时字典名称”；画板原因字段显示已保存代码，消息按保存事实原样显示。

编辑器选择原因时，将该条默认内部消息填入当前规则；如果当前已有手工修改且切换另一原因，先在页面内确认是否替换文案，取消切换保留原选择/消息。初次加载编辑页面及选项刷新均不自动重填。此确认属于产品交互，不是本次研发授权的额外流程。

标签控件使用受控多选，不使用可自由造值的 tags 模式。目标绑定仍由既有工程目录提供；更换已支持的绑定不按标签主体类型清空或禁选标签，使用含义由运营判断。字典停用/未登记的基线旧项显示相应徽标，允许删除，不能复制产生新的兼容项。旧项严格沿用判据由 Risk 决定，UI 不能传 legacy=true 绕过。

## 4. 字典维护与状态

列表操作菜单统一为“详情、编辑、引用关系、停用/启用”，按权限与当前状态呈现；点击或 hover 可打开，键盘同样可用。没有字典删除动作。

- **新增**复用编辑抽屉，编码可填，标题“新增拒绝原因/新增主体标签”，按钮“创建并启用”；名称必填，拒绝原因的默认消息必填；含义/内部说明可空，不再填写变更原因或适用主体。
- **详情**复用同一抽屉的只读内容，无保存；显示编码、内容、状态、当前 version 和创建/更新人/时间。
- **编辑**编码不可改，表单不混入启停操作；完整快照 + expectedVersion。成功关闭并刷新列表；409 保留草稿，提示重新载入后人工合并，不自动覆盖。
- **启停**二次确认对话框显示准确代码/名称和目标状态，无变更原因输入。停用说明“停用后不能新选，已有规则配置和发布保持原状”，启用说明“后续配置可重新选择”；引用数不阻止停用。确认成功后刷新，不在列表开关触发时直接乐观宣称成功。
- 标签字典不展示主体类型配置，也不调用单独的主体类型 API。规则动作目标仍从原 Authoring Context 动态读取，当前工程能力没有实现的 Consumer 绑定仍不可配置。
- 新增、编辑、启停分别检查 Resource/权限；只有 READ 的用户保留详情/引用，隐藏写入口。有规则配置权限但没有字典维护权限仍可读启用选项。

## 5. 引用图与引用明细

发布图以“发布 → 决策点版本 → 规则集版本”呈现。ACTIVE 为绿色并明确“已生效”；候选显示原状态和环境，历史 SUPERSEDED 显示“已替代”，不能只靠颜色区分。点规则集版本进入只读页面，不新增发布详情、批准或激活操作。

图和表共享同一响应页面，标明“当前页关系图”和总数；切页/筛选同步更新，不把当前页称为完整血缘。顶部“当前被使用”取所有版本的 inUse，不随页面过滤消失。图只展示发布引用，不暗示交易命中/运行轨迹。

字典引用默认 ALL（页面“全部配置归属”），列出当前配置、历史版本及已删除根。ACTIVE 环境是具体版本事实；当前配置可能未使用，历史可能正在使用。已删除条目不提供普通详情链接。返回路径保留字典类型、编码、scope 和页码。

## 6. 必须覆盖的状态和交互验收

| 状态 | 页面反馈 / 验收 |
|---|---|
| 加载中 | 内容区 skeleton，分页/查询显示正在请求；取消或忽略过期响应，晚到响应不能覆盖新选择 |
| 真正空结果 | “暂无历史版本/暂无引用/暂无字典”与“未找到匹配项”分开；有创建权限才给新增入口 |
| 查询失败 | 保留已加载内容但标识未刷新，提供重试和 Request ID；错误不渲染为空图、停用或未登记 |
| 无权限 / 会话失效 | 沿用现有权限/登录流程；页面不持续发写请求，无权按钮不进入 Tab 序列 |
| 旧项未登记/已停用 | 原代码与原值可见，不自动清空、补默认或更换；新选项里不可选择停用代码 |
| CAS 409 | 保留未提交表单，提示数据已变化，重新载入为用户明确操作 |
| 保存结果未确定 | 字典保存保留草稿，提示人工按代码刷新查询当前值/版本/更新人，不自动重发或轮询恢复；重新操作须先人工确认。原规则集命令仍保留原请求与幂等键重试 |
| 已删除/版本不属于根 | 404 页面且可返回受控来源；不再自动转到最新或另一个规则集 |
| 长内容 | 中文名称与长代码不挤压操作列；代码可复制/完整查看，消息换行，规则区独立滚动，底部操作不遮住最后字段 |
| 键盘 | 菜单 Enter/Space/方向键/Escape 可用；抽屉 focus trap、关闭恢复到触发按钮；只读文本可选择复制；操作有可见焦点 |
| 尺寸 | 1360 桌面以画板为准；1024 时收起左侧规则列表；窄于 768 使用单栏，图可横向滚动且保留等价明细列表，抽屉占满可用宽度。不能只验证大屏截图 |

本次画板展示主要正常态；空/失败/权限/并发/窄屏是上述文字定义的研发验收目标，未声称已画出或已运行这些状态。

## 7. 设计验证边界

使用 Pencil `Get` 布局诊断和截图逐页检查，修复关系图分页裁切及下拉字符缺字，改为原生图标。导出的 PNG/PDF 供设计评审；它们不是浏览器端交互测试。本次简化已移除标签主体字段/筛选与两个字典编辑抽屉的变更原因，更新标签选择提示并重新导出。阶段 5 按本文件及 AC 验证真实页面路由、可访问性、异常态、窄屏和后端联调。

## 8. 2026-09-12 人工验收后的 Web 调整

用户要求直接修改 Web 并部署 test，由用户测试，覆盖前述第 2 节和第 6 节中页面返回按钮的安排。规则编辑、当前详情、历史详情、历史列表及发布引用页统一使用浏览器返回，不再显示“返回”“返回来源页”“返回列表”，编辑器面包屑只作位置说明；刷新按钮、弹窗关闭和未保存离开提醒保留。

规则侧栏折叠为 180px 紧凑导航，直接保留两行以内的规则名称、条件数和决策摘要；完整名称及摘要可悬停或聚焦查看。序号作为小徽标，选中项使用浅蓝背景和蓝色边线；只读与编辑使用一致布局。窄屏采用可横向滚动的规则卡片，不恢复只有序号的窄条。此增量直接修改现有 Web；上文 Pencil 画板/导出保留为阶段 3 历史设计，本次未重新导出画板。
