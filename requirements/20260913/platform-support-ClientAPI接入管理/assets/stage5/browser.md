## 已执行的页面路径

- 管理员登录，两个新导航入口可用。凭证列表展示 3 个不同 Client 的有效/过期/已撤销凭证，长名称省略并保留完整 title，密钥只展示前缀。
- Client 中文名称“跨境”筛选得到 1 条；详情 → 授权记录 orders.read 的关联 API → Route 列表携带 Scope；浏览器两次返回到详情和原筛选列表。重置清空输入并恢复 3 条。
- 只读凭证详情有独立凭证/Tenant 状态、2 条授权和有效期，无保存、创建、轮换或修改授权入口。
- Scope 14 条分页：第 2 页 4 条，切换 20 条/页后回到第 1 页展示 14 条；编码过滤 orders.read 得到 1 条。
- Scope 详情只读，编辑编码不可改；名称修改成功，可选说明用键盘清空后保存为 null，详情显示空白。操作记录只显示该 Scope 的操作和原因。
- 同一 Scope：浏览器保留“我的未保存草稿”，另一真实 API 会话先写入；浏览器保存返回 409，保留草稿并禁用保存。离开保护选择“继续编辑”保留草稿，再选择“离开”回列表；最终服务器内容为另一会话的修改。
- 浏览器新建 Scope，成功后 replace 到新对象只读详情，无保存按钮；浏览器返回实际来源列表。
- Scope 凭证引用显示 3 条（包括已撤销/过期），Route 引用展示 1 条停用 CLIENT_API 路由；从引用打开既有详情。
- Route 编辑器读取 A09 动态目录，选项显示编码和名称；按新建 Scope 编码搜索、选择并保存，详情正确回显新绑定。按中文名称搜索发现问题后补修，修后复验另见本阶段验收总报告。
- 撤销弹层确认 Client、前缀、凭证 ID，红色确认按钮。取消后原状态保持有效；填写原因提交后列表显示已撤销。真实 PLT-I03 在浏览器提交前 200，提交后新认证 401，见 browser-support.json。
- 只读账号 Scope 列表无新增，操作菜单仅详情，详情无编辑；过期凭证菜单和详情均无紧急撤销。HTTP 权限拒绝另见 integration.json。
- 1440、1024、390 宽度检查：查询布局随宽度变为双列/单列，表格保持自身水平滚动；390 下导航自动收起、页面 scrollWidth=390、输入宽度各 149px，查询可用。1024 下页面 scrollWidth=1024、两个输入各 219px。本轮 viewport override 已重置。

## 验收发现与修复

1. 初始凭证查询下拉框占满容器，两个输入实际宽度为 0px，无法输入。将模式下拉固定为 124px，输入占剩余空间并增加可访问名称。重新构建后真实浏览器中文查询成功；1440 下输入宽度约 232px。
2. Scope 按中文名称搜索触发 MySQL 1270 字符集冲突，浏览器展示局部重试及 Request ID；ASCII scope_code 与 Unicode keyword 的 LIKE 比较冲突。修复与失败/通过回归记录见本阶段总报告。

重启本轮三个自有 Java 进程加载修复后的代码，使用重新创建并归属本轮的夹具。Scope 列表按“查询订单”得到 1 条；Route 编辑器按中文“查询订单”搜索出现 `orders.read · 查询订单`，选择保存后只读详情正确回显。最终浏览器 error/warn 捕获为空，已退出会话并关闭自有标签页。另有 11 项完整链 HTTP 复验覆盖两个查询入口的中文、无结果、ASCII 和大小写边界，见 search-recheck.json。
