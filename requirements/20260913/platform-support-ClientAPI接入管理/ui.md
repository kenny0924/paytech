## 2. 凭证查询与详情

- Client 搜索框通过显式模式选择“Client 名称 / Client ID”；凭证框选择“密钥前缀 / 凭证 ID”。画板默认名称与前缀模式。不同模式只提交对应字段，不根据是否全数字自动猜测：数字也可能是合法前缀。切换模式清空该框的旧值。
- 状态筛选全部、有效、已过期、已撤销；URL 保存明确筛选键与 page/size。Scope 引用跳转附 scopeCode，显示可移除的筛选标签；这些筛选与其他条件 AND。
- Client 列显示名称和 ID，前缀完整可辨，过长文本在固定列宽内省略、悬浮可看全文；不发生列相互覆盖。不增加底部内容摘要或大段提示。
- 详情分别展示凭证状态和 Tenant 状态；Tenant 停用不隐藏记录。授权表展示每条记录本身的状态与有效期，父凭证已撤销时显示简短状态说明，不能把授权记录状态当成当前 API 可调用承诺。
- “关联 API”跳到既有 Route 列表并携带 requiredScopeCode，只要求 GATEWAY_CONFIG_READ；无需先打开 Scope 详情。未登记目录也可以按其原代码查路由，名称显示“未登记”。
- 轮换来源有 ID 时可进入旧凭证只读详情；null 显示“—”。后台不投影完整凭证或 PHC，不提供秘密复制按钮。

## 3. Scope 与 Route

Scope 列表提供编码/名称搜索、分页及新增。详情沿用只读表单，无保存按钮；有维护权限时“编辑”进入同一字段布局的可编辑状态。新增编码受 API 语法约束，编辑固定编码；说明清空提交 null。目录不增加状态列或启停动作。

Scope 详情首次以 A06 NONE 读取基本资料。用户选择路由/凭证时请求对应 referenceKind 及分页，不预取全部引用或另一标签数量；分页切换仅刷新当前列表。操作记录按 API_SCOPE + scopeCode 查询既有审计。没有某项查看权限就隐藏对应标签，直接构造请求仍由后端拒绝。

API_SCOPE Route 使用支持远程搜索和分页的 Select，选项显示“编码 · 名称”，保存仍发送 requiredScopeCode 字符串。仅已有路由查看权限即可读取 A09 的编码/名称；不要求 Scope 管理权限、不展示凭证数量。尚未登记的旧原值显示“编码 · 未登记”，允许保持原值；选择新值只能来自服务端目录。失联时显示局部重试，不退回硬编码选项或手写新 Scope。

原值的名称通过 A09 有界搜索补齐，只有查询结果足以确认缺项时才标“未登记”；结果未完整覆盖或查询暂不可用时显示“原绑定”，不根据某一页未出现就判断目录缺失。

无搜索结果时，有 Scope 维护及查看权限者可从既有导航进入目录新增；没有权限者只看到“暂无匹配 Scope”。不在 Route 表单中隐式创建目录，避免保存路由产生隐藏的第二个业务写入。

## 4. 权限、撤销与错误

| 元素/动作 | 权限与状态 |
|---|---|
| 凭证入口、详情、授权记录 | API_CREDENTIAL_READ |
| 紧急撤销按钮/提交 | API_CREDENTIAL_REVOKE；页面另需 READ；已撤销对象不提供重复操作按钮，过期或 Tenant 失效的对象仍可撤销 |
| Scope 入口与基本资料 | API_SCOPE_READ |
| Scope 新增/编辑 | API_SCOPE_MANAGE；页面另需 READ |
| Route 引用/选择器 | GATEWAY_CONFIG_READ；Route 写入仍检查既有独立管理权限 |
| 凭证引用标签 | API_CREDENTIAL_READ |
| 操作记录标签 | OPERATIONS_AUDIT_READ |

撤销弹层明确展示 Client、前缀、凭证 ID；说明只撤销这一条，不能恢复，不承诺中途追回已认证请求。reason 为 1..500 字，提交携带当前 expectedVersion；提交中防重复点击。网络结果不明重试相同内容复用同一 key，用户改内容重新生成 key。

空列表显示简短空态；Scope 管理者可新增，凭证空态不出现创建入口。首次加载使用内容骨架，局部引用失败只影响当前标签。400/422 显示字段问题并保留草稿；409 保留草稿并提示刷新最新版本，禁止后台自动覆盖；401 沿用会话处理，403 显示无权限，404 显示对象不存在，503 提供重试并保留 Request ID。撤销成功后关闭弹层，重新读取详情和列表状态。

## 5. 导航与页面约束

使用现有浏览器 history 与路由约定：列表→详情→来源/引用均 push，查询和分页在同一列表使用 replace，恢复 URL 筛选及分页；标签切换 replace，避免返回键遍历多个内部状态。新增成功 replace 到详情，使返回回到来源列表；编辑成功 replace 回详情，不重新插入同一页面。直达详情时返回浏览器真实上一页，不强制跳审计页。

页面不增加“返回来源”“返回列表”等按钮。弹层取消只关闭弹层；表单采用现有未保存草稿离开保护。多功能菜单支持点击、悬浮和键盘打开，Escape 关闭；危险操作使用红色，普通链接不滥用红色。桌面固定操作列、长文本省略；窄视窗沿用现有表格水平滚动与表单单列，不能靠溢出覆盖其他列。

本阶段产出设计图和交互合同，不代表 Web 已实现或已进行浏览器功能验收；研发与真实链验证在后续阶段完成。
