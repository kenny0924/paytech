## 阶段 5 整链路发现与修复

真实 Web 入口 → Gateway → BFF → Platform 调用 A18 权限选择器时，PLT-I02 的普通会话允许清单尚未包含新 Route，返回 403。按已批准 design.md 的 A18 合同补齐该接口接入；强制改密与 Bootstrap 会话仍由原有前置限制拦截，真实 Permission 查询继续按 usage 校验 CONSOLE_RESOURCE_READ / GATEWAY_CONFIG_READ。先增加真实 HTTP 用例得到 allowed=false 的失败证据，再实现窄修复并复跑完整 Platform 验证。

手工验收启动器同步遵守现有 localhost HTTP test Profile、服务发现和入口 Channel Header 边界。最初退出时发现 Spring 自动关闭连接池与夹具清理竞态，按已记录的合成对象 ID 精确清理该次数据；启动器关闭自动 hook，统一先清理自有记录再关闭应用。这些均为本机验收机制，未调整生产安全边界。
