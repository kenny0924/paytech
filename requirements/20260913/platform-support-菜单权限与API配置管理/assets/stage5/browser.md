# 本机浏览器观察记录

使用 Codex In-app Browser，访问本任务的本机 HTTP 入口及实际 Web 生产构建；所有 API 经过真实 Gateway / BFF / Platform。仅使用合成账号与自有数据。

1. 管理账号登录后，平台配置展开显示 API 路由管理、菜单与按钮、权限目录。
2. 菜单树加载 43 个资源（42 个初始资源 + 1 个合成目录），显示名称、缩进、启停状态和操作菜单。
3. 合成目录详情字段禁用、保存按钮数量为 0；编辑可填写名称与原因。
4. 名称改为“浏览器验收目录”，浏览器返回弹出草稿确认；继续编辑保留两项输入，保存成功后真实回读显示新名称并进入只读详情。
5. 再次编辑填写未保存名称，浏览器返回后确认离开，返回原 `mode=view` 详情，新草稿没有写入。
6. 权限编码精确查询得到 1 行；详情复用只读表单。使用关系显示菜单 / 按钮 1、API 路由 0、角色 1，并能读取实际授权角色。浏览器返回恢复原编码筛选。
7. 权限编码文本较长时，语义点击的元素中心处于表格裁剪区；点击截图中实际可见的编码文本成功进入详情。操作菜单的详情跳转同样通过，没有修改应用代码。
8. 新动态 Route 列表回读停用状态、版本 4；详情完整显示根字段、Header、Query 和两项 Guard，输入禁用，无保存。
9. 新建 Route 的 Channel 选项从真实能力接口加载 OPERATIONS、CLIENT、PARTNER、CHECKOUT、CLIENT_API、CHANNEL_CALLBACK；空表单保存显示逐字段必填错误，没有生成对象。
10. 默认 1280 宽度观察菜单树与权限列表。1024 × 768 及 768 × 900 观察 Route 详情，文档宽度分别等于 1024 / 768，无页面横向溢出；768 下表单改为纵向排列。临时视口覆盖已恢复。
11. 只读人员可查看菜单树，新增按钮不存在，操作菜单仅详情，详情无编辑 / 保存。恢复上一次新建 Route URL 时表单同样禁用，无写入入口。
12. 没有新读取权限的人员直接恢复资源详情 URL，显示“暂无访问权限”，新资源管理页不在可用菜单清单。
13. 验收最后读取浏览器 error / warn 日志为空，退出账号并关闭本次页面。

本记录为浏览器实际观察；没有把设计 PNG、接口 Simulator 或纯静态断言当成真实页面截图验收。服务故障与所有组合分支的依据由 acceptance.md 区分复用的自动化证据。
