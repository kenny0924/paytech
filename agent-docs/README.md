# Agent 文档导航

本目录保存 Code-MoR 的长期设计上下文和开发规范。Agent 必须按任务类型选择性读取文档，避免只依赖根目录摘要，也避免为无关任务加载全部资料。

> **当前 Platform 路由：** [统一人工认证设计](../docs/superpowers/specs/2026-08-30-platform-unified-human-authentication-design.md) 管理 Account/Realm/Channel/Tenant、CCT Application 与 Risk typed namespace；[57 表数据库精简设计](../docs/superpowers/specs/2026-09-01-platform-support-database-simplification-design.md)及其[实施记录](./plans/2026-09-01-platform-support-database-simplification-implementation-plan.md)是未受公共控制面影响领域的前序基线，[统一公共 API 动态控制面设计](../docs/superpowers/specs/2026-09-01-gateway-platform-support-dynamic-operations-configuration-design.md)及其[PDManer 实施计划](../docs/superpowers/plans/2026-09-01-platform-public-api-control-plane-pdmaner.md)管理当前 Platform 物理边界。CCT 当前为 `37/423/57/44/64/7/6`；Platform 当前为 `63/822/123/99/107/5/7`、31 composite FKs、85 named CHECK sidecar contracts 与恰好 36 个 `*_hash` 字段。已取代的数据库 Gateway、通用配置和持久化 Readiness 结构仅为历史；Commerce、Payment、Finance 和 Risk 当前事实不受影响。

> **当前 Platform 实现：** [`platform-support-service`](../platform-support-service/README.md) 已验证 `api`/`web`/`test` 三模块、Spring MVC 与同端口 Actuator，并实现 Phase A MyBatis 21-table 投影、手工 Schema/初始化 DML 及私网 HTTP PLT-I20 全量 typed Snapshot Provider。PLT-I20 与 Actuator 不包含 Spring Security、X.509/mTLS 或本地 HTTP 异常处理器，统一复用 Foundation MVC 错误边界。[手工基础设施与运行时精简决策](../docs/superpowers/specs/2026-09-02-manual-infrastructure-and-platform-runtime-simplification.md)取代早期 Flyway/Testcontainers/Java Seed 机制。认证/Tenant IAM 命令、Target/Route/Console 管理 API、Nacos/MQ/Redis、BFF、Gateway Snapshot 消费与部署尚未实现。

> **当前 Vault 路由：** [Vault V1 三表设计](../docs/superpowers/specs/2026-09-02-vault-database-design.md)、[物理建模决策](../vault-service/docs/database/VAULT_PHYSICAL_DECISIONS.md)与[生成模型](../vault-service/docs/database/vault.pdma.json)是 API、调用者识别、Token、拓扑、加密持久化、Protect 幂等和本地访问审计的当前权威。`VAULT_SERVICE_ARCHITECTURE.md` 中强制 Binding、mTLS/Workload Identity、广泛 API/生命周期、18 表拓扑、复杂幂等与 Platform 审计部分在被三表设计取代处仅为历史；非卡/PCI 排除、内部专用、业务含义仍归业务系统、禁止直读 Vault 数据库以及 KMS/Secrets 分离等未受影响安全边界继续有效。当前信任假设只是部署网络约束下的私网 HTTP、必需但可伪造的 `X-Caller-Service` 与静态 Allowlist，不是强服务认证，Java 应用不持有 X.509 证书。

> **当前传输与 MVC 基线：** [MVC Web 日志、统一异常与内部 HTTP 精简设计](../docs/superpowers/specs/2026-09-02-mvc-web-logging-and-internal-http-simplification-design.md)规定公网 TLS 在 Nginx 终止，Nginx 覆盖一个 `X-Real-IP`，Gateway 只从私有 Nginx 网络接入、解析一次该地址供 Guard/访问日志使用并在转发 BFF 前删除代理 Header；Gateway、BFF、Platform、Vault 与核心 Java 服务之间使用私网 HTTP，不持有 X.509 证书。MVC 服务由 `paytech-mvc-web-starter` 自动获得完整 Request/Response/耗时 `INFO` 日志和统一 `GlobalExceptionHandler`，不得逐服务重复实现。

> **当前 MyBatis 基线：** [Foundation MyBatis TypeHandler 设计](../docs/superpowers/specs/2026-09-03-foundation-mybatis-type-handlers-design.md)规定 `paytech-mybatis-support` 统一提供 UTC `Instant` 和内部 `CodeEnum` 映射。DataObject 使用强类型枚举并显式注册 Handler，未知数据库 Code Fail-Closed；外部 API/MQ DTO 继续使用字符串 Code，每个 DataObject 字段必须有说明约束的中文 JavaDoc。

## 六大核心系统数据库文档
