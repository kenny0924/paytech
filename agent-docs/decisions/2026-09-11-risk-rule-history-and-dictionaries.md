# Risk 规则历史查看与业务字典范围决定

- Decision status: Confirmed（用户确认功能范围及阶段 2 兼容方向；阶段 3 用户明确移除标签适用主体关系与字典变更回执；其余精确接口、模型和兼容判据待评审）。
- Decision date: 2026-09-11。
- 当前实现、验证、部署状态：[CURRENT_IMPLEMENTATION.md](../CURRENT_IMPLEMENTATION.md)；本决定不证明研发或部署完成。
- 确认来源与阶段记录：[delivery.md](../../requirements/20260911/operations-console-风控规则集历史与字典管理/delivery.md)。

## 1. 精确取代范围

1. 取代[上一轮配置决定](./2026-09-11-risk-rule-v1-configuration.md)第 4–5 节中“本期不建标签/拒绝原因字典、标签与拒绝原因一律手工输入”的后续功能边界。本需求建设两类字典，文案属于原因字典，选中默认文案后允许在规则内调整；不重写上一轮已执行 SQL 或历史配置。
2. 取代[规则集列表需求](../../requirements/20260911/operations-console-风控规则集列表优化/requirement.md)及[方案](../../requirements/20260911/operations-console-风控规则集列表优化/technique.md)中“多版本展示延期、详情继续 Drawer”的后续目标。本需求提供独立历史版本列表，并将当前/历史详情统一为编辑器布局的只读页面。
3. 发布引用关系查询是新增只读功能；不取代整集删除、永久编码、ACTIVE 使用判定、当前配置单行列表、Candidate 后端保留和界面隐藏。

## 2. 已确认决定

- 列表详情看最新保存配置，历史查看看明确选中的版本；查看无保存和修改操作，但能切换规则、展开内容和查看基本信息，查询权限不依赖编辑权限。
- 历史列表显示版本号、保存人、保存时间和变更原因，按版本倒序。版本比较、恢复或覆盖历史不纳入。
- 使用关系以真实发布引用呈现图与明细，区分环境和当前 ACTIVE、候选、历史非活动关系；不是实际交易调用或命中轨迹。字段/动作的完整依赖展开继续后续处理。
- Risk 拥有拒绝原因字典、主体标签字典及被规则引用查询；支持查询、新增、编辑和启停，编码固定不复用。默认拒绝文案为内部用途，仍随具体规则版本保存。
- 字典修改、停用不改写历史规则内容或 Hash；历史未登记代码和已有消息仍可原样查看。阶段 2 已确认同一持久化基线原样沿用旧项、新增/替换校验当前目录的方向；具体元组/计数判据见待评审 [data.md](../../requirements/20260911/operations-console-风控规则集历史与字典管理/data.md)，不得提前当作已批准迁移。
- 用户在本次评审明确取消标签适用主体限制，不建关系表、单主体字段或类型数组；标签含义由人工维护。规则动作的目标绑定仍由 Web/BFF 动态消费真实工程目录，不让运营注册未知输入或执行能力。字典定义不产生主体标签实例、冷却、评估或其他副作用。

字典变更回执同样按用户要求移除：只维护当前目录及创建/最后更新信息，写入使用编码唯一和版本校验，未知结果由人工刷新确认；不建立历史响应表或替代 JSON，不扩展原幂等存储。原规则集命令的幂等和历史回放保持。

## 3. 不变边界与后续合同

原 v1 接口继续原地演进，新接口默认 v1，类型不使用协议版本后缀。业务版本、旧 Wire/Hash 和命令回放继续按兼容合同保护。冻结/Candidate 的执行就绪检查不能被字典功能绕过。

本次只补齐上述功能，其他优化不混入；不扩展公共基础字典、不新建图数据库、通用字典服务或运行执行系统。详细需求由[requirement.md](../../requirements/20260911/operations-console-风控规则集历史与字典管理/requirement.md)拥有；阶段 2 分析和待评审细节在[technique.md](../../requirements/20260911/operations-console-风控规则集历史与字典管理/technique.md)。
